Installieren Sie die App, verbinden Sie ein Modell und beginnen Sie ein Gespräch.

Anleitung für den ersten Start →
Welche Architektur soll ich wählen?

Öffnen Sie auf dem Mac das Apple-Menü → Über diesen Mac: Ein Apple-M-Chip bedeutet Apple silicon, ein Intel-Prozessor bedeutet Intel. Unter Windows finden Sie die Architektur unter Einstellungen → System → Info. Unter Linux zeigt der Befehl uname -m folgende Werte: x86_64 für x64 oder aarch64 für ARM64.

Wie installiere ich Ocean?

Öffnen Sie unter macOS das DMG oder entpacken Sie das ZIP und verschieben Sie die App nach Programme. Starten Sie unter Windows das heruntergeladene Installationsprogramm. Entpacken Sie unter Linux das TAR.GZ, öffnen Sie den entpackten Ordner im Terminal und führen Sie folgenden Befehl aus: ./ocean. Falls Sie ein AppImage heruntergeladen haben, erlauben Sie in den Dateieigenschaften die Ausführung. Mehr zur Installation.

Was brauche ich nach der Installation?

Öffnen Sie Einstellungen → Modelle und klicken Sie auf Modellanbieter hinzufügen. Geben Sie die Verbindungsdaten ein und klicken Sie auf Anwenden. Erstellen Sie anschließend eine neue Sitzung und wählen Sie ein Modell. Einrichtung und erste Aufgabe.
