Browser Control

Browsersteuerung

Ihr Chrome mit gespeicherten Anmeldungen. Lesen Sie Seiten, füllen Sie Formulare aus und verwalten Sie Tabs über den Chat.

Sie wählen die freigegebenen Websites und können Ocean einen bereits geöffneten Tab übergeben.

Computer Use

App-Steuerung

Oberflächen lesen, Fenster aufnehmen, klicken, Text eingeben und in freigegebenen Apps scrollen.

Richten Sie den Zugriff im Bereich Plugins von Ocean ein. Die verfügbaren Aktionen hängen vom Betriebssystem ab.

So verbinden Sie sich →

Super Agent

Aufgabenboard

Ein dauerhaftes Entwicklungsboard: Der Agent übernimmt eine Aufgabe in einem eigenen Git-Worktree, führt die Repository-Prüfungen aus und meldet das Ergebnis.

Die Arbeit überlebt die Sitzung: Das Board bleibt, und der Executor führt die Aufgabe zu einem geprüften Ergebnis.

Agent Developer Patterns

Entwicklungsmuster für Agenten

Ein Dispatcher-Skill: Er benennt die aktuelle Phase und übergibt ein fertiges Verfahren — Plan, Interview, TDD, hypothesengetriebenes Debugging, Review oder Übergabe.

Funktioniert aus dem Bundle selbst; zusätzliche Skill-Sets sind optional.

Remotion studio

Video-Studio

Erstellen Sie ein Remotion-Projekt aus einer Vorlage, sehen Sie es in Studio an und rendern Sie ein MP4, ohne den Dialog zu verlassen.

Das Rendern läuft als Hintergrundaufgabe, sodass ein langes Encoding den Chat nicht blockiert.

Theme picker

Oberflächenthemen

Siebenundzwanzig Paletten: Abyss, One Dark/Light, Dracula/Alucard, GitHub, Solarized, Nord, Tokyo Night, Catppuccin, Gruvbox, Everforest, Rosé Pine, Kanagawa, Ayu, Night Owl, Material, Flexoki, Modus, Darcula, Mariana, Oxocarbon, PaperColor, Seoul256, Monokai, SynthWave '84, Cobalt2, Horizon und Jellybeans.

Ein einziges Auswahl-Bundle malt die Oberfläche in beiden Schemata neu und lässt „Darstellung“ unangetastet.
