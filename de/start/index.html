Schritt 01

Installieren Sie Ocean

Wählen Sie auf der Downloadseite Ihr System und Ihre Architektur.

Download auswählen ↓
macOS
  1. Öffnen Sie das DMG oder entpacken Sie das heruntergeladene ZIP.
  2. Verschieben Sie die Ocean-App in den Ordner Programme.
  3. Starten Sie Ocean aus diesem Ordner.

Apple silicon ist für Apple-M-Chips geeignet. Den Prozessortyp finden Sie im Apple-Menü → Über diesen Mac.

Windows
  1. Laden Sie das Installationsprogramm herunter, sobald es für Ihr System verfügbar ist.
  2. Öffnen Sie die Datei und folgen Sie den Installationsschritten.
  3. Starten Sie Ocean über das Startmenü.
Linux
  1. Entpacken Sie das TAR.GZ-Archiv in einen eigenen Ordner.
  2. Lassen Sie alle Dateien aus dem Archiv zusammen.
  3. Öffnen Sie im entpackten Ordner ein Terminal und starten Sie ./ocean.

Der Befehl uname -m hilft bei der Auswahl der Architektur: x86_64 — x64, aarch64 — ARM64.

Schritt 02

Verbinden Sie Ihr Modell

Für das erste Gespräch reichen ein Anbieter und dessen API-Schlüssel.

  1. Öffnen Sie Einstellungen → Modelle

    Klicken Sie auf Modellanbieter hinzufügen und wählen Sie einen Anbieter aus dem Katalog. Wenn er bereits aufgelistet ist, öffnen Sie Bearbeiten.

  2. Fügen Sie einen API-Schlüssel hinzu

    Holen Sie den Schlüssel im Kundenbereich Ihres Anbieters, fügen Sie ihn in das Feld API-Schlüssel ein und klicken Sie auf Anwenden.

  3. Prüfen Sie, ob der Schlüssel gespeichert ist

    Beim Anbieter erscheint API-Schlüssel konfiguriert. Mit der ersten Nachricht prüfen Sie, ob das Modell funktioniert.

Modellzugriff und Anfragekosten bestimmt Ihr Anbieter. Wenn Sie ein Konto über ein Plugin verbinden, melden Sie sich in dessen Plugin-Karte an.

Schritt 03

Erhalten Sie die erste Antwort

Beginnen Sie mit einer kleinen Aufgabe. Für dieses Beispiel ist kein Zugriff auf Browser oder Apps nötig.

  1. Erstellen Sie einen Chat

    Klicken Sie links auf Neue Sitzung. Wählen Sie unter dem Nachrichtenfeld das verbundene Modell.

  2. Beschreiben Sie die Aufgabe

    Probieren Sie das Beispiel von der Startseite. Es enthält bereits den gesamten nötigen Kontext:

    Erstelle einen Ablauf für eine 30-minütige Teambesprechung. Wir müssen den Starttermin abstimmen, die verbleibenden Aufgaben verteilen und festlegen, wer das Ergebnis prüft. Hebe die anstehenden Entscheidungen hervor.

  3. Setzen Sie das Gespräch fort

    Senden Sie die Nachricht mit der Pfeilschaltfläche. Präzisieren Sie nach der Antwort die Aufgabe — bitten Sie zum Beispiel darum, die Besprechung auf 20 Minuten zu kürzen.

Wenn Sie sich eingelebt haben

Verbinden Sie Ihre Werkzeuge

Plugins ermöglichen die Arbeit mit Websites und Apps. Sie wählen den Zugriff.

Chrome verbinden →Apps verbinden →

Wenn keine Antwort kommt

Prüfen Sie das ausgewählte Modell, den API-Schlüssel und das verfügbare Guthaben im Kundenbereich Ihres Anbieters. Wenn Ocean einen Fehler anzeigt, kontaktieren Sie den Support und fügen Sie den Fehlertext ohne Schlüssel und Passwörter bei.
