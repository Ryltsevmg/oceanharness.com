Before your first launch

A few simple steps

Install the app, connect a model and start a conversation.

First launch guide →
Which architecture should I choose?

On a Mac, open the Apple menu → About This Mac: an Apple M chip means Apple silicon; an Intel processor means Intel. On Windows, check Settings → System → About. On Linux, the command uname -m shows x86_64 for x64 or aarch64 for ARM64.

How do I install Ocean?

On macOS, open the DMG or extract the ZIP and move the app to Applications. On Windows, run the downloaded installer. On Linux, extract the TAR.GZ, open the extracted folder in a terminal and run ./ocean. If you downloaded an AppImage, allow the file to run in its properties. More about installation.

What do I need after installation?

Open Settings → Models and click Add model provider. Enter your connection details and click Apply. Then create a new session and select a model. Setup and your first task.
