Computer Use

Your apps.
Ocean's help.

Let Ocean read interfaces and carry out tasks in the apps you need. You choose access for each app.

01 Enable plugin02 Set up system03 Test in chat

Step 01

Enable the plugin

Start in Plugins in Ocean's sidebar.

  1. Open Computer use

    Turn on the switch in the plugin card. If Ocean asks you to restart, do so.

  2. Keep the card open

    It shows system readiness and app access permissions.

If the card is not listed, the plugin is not installed yet. Contact support — we will help you install it for your system.

Step 02

Prepare your system

Choose your OS. Plugin capabilities vary by platform.

macOS
  1. Click Request permission in the Accessibility and Screen recording rows.
  2. In system settings, allow access for the app shown in Ocean's panel.
  3. Return to Ocean. Both permissions should show Allowed.

Once set up, you can read interfaces, capture windows, click, type and scroll.

Windows
  1. Run Ocean in a regular Windows session with the desktop unlocked.
  2. Check Interactive desktop and Window capture in the card.
  3. Keep the target app in the foreground for mouse and keyboard actions.

Interface reading, window capture and control are available. Apps running as administrator may deny access.

If the native component is unavailable, contact support to set it up for your system.

Linux
  1. Run Ocean in your local graphical session and unlock the desktop.
  2. Check AT-SPI availability in the card. System Python 3, PyGObject and AT-SPI are required; the plugin does not install them automatically.
  3. Open an app that supports AT-SPI.

Reading interface elements and performing actions exposed by the app are supported. Screenshots, standard mouse and keyboard input, and launching apps are not supported.

Step 03

Test access in chat

Start by reading a window. A model must be connected in Ocean.

  1. Open the app you need

    Choose a window without personal data, such as a text editor with a test note.

  2. Ask Ocean to look at the window

    Read the open window of my text editor and briefly describe what is visible. Do not change anything.

    Include your editor's name if several apps are open.

  3. Approve access

    Ocean will request permission for the selected app. Once approved, it will read the available elements and respond in chat.

You control access

Stop or revoke

Click Stop in chat to interrupt the current task. In the plugin card, click Revoke next to an app to remove its permission.

Apps appear in the list after access requests. An empty list before your first task is normal.
