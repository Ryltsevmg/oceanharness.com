Clear about data

Your data in Ocean

Chats are saved on your computer. To generate a response, Ocean sends context to your chosen model, while connected tools contact the services needed for the task.

On your device

Chat history, settings and saved connections.

With the model provider

Messages and materials included in the request.

Under your control

Your choice of model, plugins, websites and apps.

What is stored locally

In standard desktop mode, Ocean stores message and tool-action history, attachments, settings and connection data in the app's data folder. By default, this is ~/.ocean; you can change the location in a custom configuration.

API keys and authorization data are stored separately from the settings text. Protection of local files depends on access to your computer: this storage is not isolated from all agent tools.

What the model receives

Requests are sent to the provider you connected. They may include chat messages, files read for the task, page text, window captures and tool results. Storing history locally does not mean model processing also happens locally.

The provider's retention periods and use of data are governed by its terms and your account settings. Search services, external tools and third-party plugins also have their own data-handling rules.

Browser and apps

Choose allowed websites and apps in the relevant plugin's settings. Captures and content read by tools may become part of the chat and model request. You can revoke access and disable the plugin.

The Chrome extension's permissions, pairing and data storage are described separately: Browser Control privacy.

Log sharing and diagnostics

When using the DeepSeek adapter, there is a separate setting called “Send log with DeepSeek API requests” in Settings → General. It is enabled in the default configuration: the chat log, including messages and tool results, is added to API requests. Re-enabling it may also send previously accumulated records.

Separate log uploads to a telemetry service are disabled in Ocean's default configuration. Product analytics require an explicitly configured recipient and separate activation.

The DeepSeek adapter also sends a random installation identifier that persists between launches. This is independent of the telemetry setting.

If you use a custom configuration

Your configuration may include other data recipients. When enabled, the built-in feedback mechanism sends the log up to the point of the feedback, including context. Check the settings of your build and connected providers.

How to manage saved data

Archiving hides a chat from the main list but does not delete its log. Deleting a workspace does not delete its folder or chat history either.

To delete all local Ocean data, first close the app and save any results you need, then delete the app's data folder. This also deletes local chats, settings and saved connections for every profile in that folder. If you use a nonstandard data location, confirm the path with supportbefore deleting files.

This does not delete your project files, external backups, Chrome extension data or materials already sent to providers. Manage those in the relevant app or service.

What this website does

The website has no registration forms, advertising trackers or embedded third-party analytics. Fonts and images are loaded from the Ocean domain. The downloads page requests the list of published files from GitHub.

The site is hosted on GitHub Pages. When you visit the site, GitHub or external links, the corresponding services receive standard network request data. GitHub's rules are described in its privacy policy.

Questions about data

Contact Ocean support or email support@oceanharness.com. Do not include API keys, passwords or a full chat log unless necessary.
