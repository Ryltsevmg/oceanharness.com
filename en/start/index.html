Dive in

From first launch
to your first task.

Install Ocean, connect a model and start a conversation. Add the browser and apps later.

01 Install Ocean 02 Connect a model 03 Give it a task

Step 01

Install Ocean

Choose your system and architecture on the download page.

Choose a download ↓
macOS
  1. Open the DMG or extract the downloaded ZIP.
  2. Move the Ocean app to your Applications folder.
  3. Launch Ocean from that folder.

Apple silicon is for Apple M chips. You can check your processor in the Apple menu → About This Mac.

Windows
  1. Download the installer when it is available for your system.
  2. Open the file and follow the installation steps.
  3. Launch Ocean from the Start menu.
Linux
  1. Extract the TAR.GZ archive into a separate folder.
  2. Keep all files from the archive together.
  3. Open a terminal in the extracted folder and run ./ocean.

The command uname -m helps you choose the architecture: x86_64 — x64, aarch64 — ARM64.

Step 02

Connect your model

For your first conversation, all you need is one provider and its API key.

  1. Open Settings → Models

    Click Add model provider and choose a provider from the catalog. If it is already listed, open Edit.

  2. Add an API key

    Get a key from your provider's dashboard, paste it into the API key field and click Apply.

  3. Make sure the key is saved

    The provider will show API key configured. Your first message will test that the model works.

Your provider determines model access and request pricing. If you connect an account through a plugin, sign in from that plugin's card.

Step 03

Get your first response

Start with a small task. This example does not need access to your browser or apps.

  1. Create a chat

    Click New session in the left panel. Select your connected model below the message field.

  2. Describe the task

    Try the example from the home page. It already includes all the context you need:

    Create a 30-minute team meeting agenda. We need to agree on a launch date, assign the remaining tasks and choose who will review the result. Highlight the decisions we need to make.

  3. Continue the conversation

    Send the message using the arrow button. After the response, refine the task — for example, ask to fit the meeting into 20 minutes.

When you are ready

Connect your tools

Plugins add website and app capabilities. You choose the access.

Connect Chrome →Connect apps →

If no response arrives

Check the selected model, your API key and your available balance in the provider's dashboard. If Ocean shows an error, contact support and include the error text without keys or passwords.
