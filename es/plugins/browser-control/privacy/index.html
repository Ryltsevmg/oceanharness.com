Privacidad de Browser Control

En vigor desde el 16 de noviembre de 2026. Esta política se aplica a la extensión Ocean Browser Control para Chrome. Para conocer cómo la aplicación guarda los chats y trata los datos, consulta «Tus datos en Ocean».

Qué hace la extensión

La extensión conecta Chrome con un servicio de enlace vinculado para que Ocean pueda controlar las pestañas de tareas y las pestañas que compartas mediante el botón de la barra del navegador. Ocean tiene un ajuste independiente de sitios autorizados. Los permisos de Chrome son más amplios que ese ajuste: la restricción se aplica en la aplicación, no en un entorno aislado de Chrome independiente.

Qué datos se tratan

Cuando se le solicita, la extensión puede leer el texto y la estructura de las páginas, direcciones, títulos de pestañas, capturas de pantalla y valores de campos; pulsar elementos, introducir texto y gestionar pestañas. Las páginas pueden contener datos personales, información de autenticación, datos financieros, de salud u otra información sensible. El servicio de enlace también admite la grabación de pestañas compartidas cuando se solicita. Las sesiones de los sitios permanecen en tu perfil de Chrome y se usan a través de la sesión normal del navegador.

Adónde se envían los datos

Por defecto, la extensión intercambia comandos y resultados con un servicio de enlace en tu ordenador. En los ajustes avanzados puedes indicar un servicio de tu elección en otro ordenador. Usa solo un servicio y una red en los que confíes. Ocean puede enviar el contenido de las páginas y las capturas de pantalla al proveedor del modelo elegido para la tarea. En ese caso, se aplican las condiciones y la política de privacidad de ese proveedor. La extensión no elige el proveedor del modelo.

La extensión no tiene un servicio publicitario ni de analítica, y no envía datos del navegador a un servidor de recopilación de Ocean. Los datos del navegador se utilizan para las acciones solicitadas: no se venden ni se usan para publicidad, elaboración de perfiles u otros fines ajenos. El uso y la transferencia de datos cumplen la política de datos de usuario de Chrome Web Store y sus requisitos de Limited Use.

Almacenamiento y eliminación

La extensión guarda los datos de vinculación y los ajustes en el almacenamiento de extensiones de Chrome. Los datos de acceso al servicio de enlace y los registros de tareas de Ocean se guardan por separado. Al eliminar la extensión, se elimina su almacenamiento local. Los registros de chats de Ocean, los archivos del servicio de enlace y las copias ya enviadas al proveedor del modelo permanecen; debes gestionarlos en la aplicación o el servicio correspondiente.

Permisos de Chrome

  • debugger: inspeccionar páginas compartidas, realizar capturas de pantalla y ejecutar acciones en el navegador mediante Chrome DevTools Protocol.
  • tabs y tabGroups: gestionar pestañas de tareas y agruparlas por sesiones de agente.
  • storage: guardar localmente los datos de vinculación y los ajustes.
  • alarms: reconectar con el servicio de enlace tras la suspensión del proceso en segundo plano de la extensión.
  • offscreen y tabCapture: procesar las grabaciones solicitadas de pestañas compartidas.
  • webNavigation: asociar ventanas emergentes y navegación con las pestañas de la tarea.
  • scripting: ejecutar los scripts auxiliares incluidos en la extensión para interactuar con las páginas.
  • notifications: notificarte cuando una tarea requiera tu participación.
  • Acceso a todos los sitios: trabajar con los sitios elegidos por el usuario y contactar con el servicio configurado. La extensión no solicita acceso a toda la base de datos del historial de navegación.

Tu control

Elige los sitios autorizados en Ocean, comparte explícitamente las pestañas existentes y desactiva el plugin o la extensión para dejar de usarlos. Revisa las tareas antes de permitir acciones en páginas con datos sensibles. No introduzcas secretos en una tarea si no deseas enviarlos al proveedor del modelo elegido.

Contacto

Para preguntas de privacidad y solicitudes relacionadas con los datos, escribe a support@oceanharness.com o contacta con el soporte de Ocean. Las actualizaciones de esta política se publicarán en esta página con una nueva fecha de entrada en vigor.
