Computer Use

Tus aplicaciones.
La ayuda de Ocean.

Permite que Ocean lea la interfaz y realice tareas en las aplicaciones que necesitas. Tú decides el acceso a cada aplicación.

01 Activar plugin02 Configurar el sistema03 Probar en el chat

Paso 01

Activa el plugin

Empieza en la sección «Plugins» de la barra lateral de Ocean.

  1. Abre «Uso del ordenador»

    Activa el interruptor de la tarjeta del plugin. Si Ocean te pide reiniciar, hazlo.

  2. Deja la tarjeta abierta

    Aquí aparecen el estado del sistema y los permisos de acceso a las aplicaciones.

Si la tarjeta no aparece en la lista, el plugin aún no está instalado. Contacta con soporte y te ayudaremos a instalarlo en tu sistema.

Paso 02

Prepara el sistema

Elige tu sistema operativo. Las funciones del plugin varían según la plataforma.

macOS
  1. En las filas «Accesibilidad» y «Grabación de pantalla», pulsa «Solicitar permiso».
  2. En los ajustes del sistema, autoriza el acceso a la aplicación indicada en el panel de Ocean.
  3. Vuelve a Ocean. Ambos permisos deben mostrar el estado «Permitido».

Tras la configuración, podrás leer la interfaz, capturar ventanas, hacer clic, introducir texto y desplazarte.

Windows
  1. Inicia Ocean en una sesión normal de Windows con el escritorio desbloqueado.
  2. Comprueba «Escritorio interactivo» y «Captura de ventanas» en la tarjeta.
  3. Para usar el ratón y el teclado, mantén la aplicación deseada en primer plano.

Se permiten la lectura de interfaces, las capturas de ventanas y el control. Las aplicaciones ejecutadas como administrador pueden denegar el acceso.

Si el componente nativo no está disponible, contacta con soporte para configurarlo en tu sistema.

Linux
  1. Inicia Ocean en tu sesión gráfica local y desbloquea el escritorio.
  2. Comprueba la disponibilidad de AT-SPI en la tarjeta. Se necesitan Python 3 del sistema, PyGObject y AT-SPI; el plugin no los instala automáticamente.
  3. Abre una aplicación compatible con AT-SPI.

Se pueden leer los elementos de la interfaz y realizar las acciones que ofrece la aplicación. No se admiten capturas de pantalla, entrada normal de ratón y teclado ni el inicio de aplicaciones.

Paso 03

Comprueba el acceso en el chat

Para empezar, basta con leer una ventana. El modelo debe estar conectado en Ocean.

  1. Abre la aplicación deseada

    Elige una ventana sin datos personales, como un editor de texto con una nota de prueba.

  2. Pide a Ocean que observe la ventana

    Lee la ventana abierta de mi editor de texto y describe brevemente lo que ves. No cambies nada.

    Indica el nombre de tu editor si hay varias aplicaciones abiertas.

  3. Autoriza el acceso

    Ocean solicitará permiso para la aplicación elegida. Tras tu confirmación, leerá los elementos disponibles y responderá en el chat.

Tú controlas el acceso

Detener o revocar

Pulsa «Detener» en el chat para interrumpir la tarea actual. En la tarjeta del plugin, pulsa «Revocar» junto a la aplicación para retirar su permiso.

La lista de aplicaciones se completa tras las solicitudes de acceso. Es normal que esté vacía antes de la primera tarea.
