a tu primera tarea.

Instala Ocean, conecta un modelo e inicia una conversación. Puedes añadir el navegador y las aplicaciones más adelante.

01 Instalar Ocean 02 Conectar un modelo 03 Plantear una tarea

Paso 01

Instala Ocean

Elige tu sistema y arquitectura en la página de descargas.

Elegir descarga ↓
macOS
  1. Abre el DMG o descomprime el ZIP descargado.
  2. Mueve Ocean a la carpeta «Aplicaciones».
  3. Inicia Ocean desde esa carpeta.

Apple silicon corresponde a los chips Apple M. Consulta el tipo de procesador en el menú Apple → «Acerca de este Mac».

Windows
  1. Descarga el instalador cuando esté disponible para tu sistema.
  2. Abre el archivo y sigue los pasos de instalación.
  3. Inicia Ocean desde el menú «Inicio».
Linux
  1. Descomprime el archivo TAR.GZ en una carpeta independiente.
  2. Mantén juntos todos los archivos del paquete.
  3. Abre el terminal en la carpeta extraída y ejecuta ./ocean.

El comando uname -m te ayudará a elegir la arquitectura: x86_64 — x64, aarch64 — ARM64.

Paso 02

Conecta tu modelo

Para la primera conversación, basta con un proveedor y su clave API.

  1. Abre «Ajustes» → «Modelos»

    Pulsa «Añadir proveedor de modelos» y elige un proveedor del catálogo. Si ya está en la lista, abre «Editar».

  2. Añade la clave API

    Obtén la clave en tu cuenta del proveedor, pégala en el campo «Clave API» y pulsa «Aplicar».

  3. Comprueba que la clave se haya guardado

    El proveedor mostrará «Clave API configurada». Comprobaremos el modelo con el primer mensaje.

Tu proveedor determina el acceso a los modelos y el coste de las solicitudes. Si conectas una cuenta mediante un plugin, inicia sesión desde la tarjeta de ese plugin.

Paso 03

Recibe tu primera respuesta

Empieza con una tarea pequeña. Este ejemplo no requiere acceso al navegador ni a las aplicaciones.

  1. Crea un chat

    Pulsa «Nueva sesión» en el panel izquierdo. En la parte inferior del campo de mensaje, elige el modelo conectado.

  2. Describe la tarea

    Prueba el ejemplo de la página de inicio. Ya incluye todo el contexto necesario:

    Crea un plan para una reunión de equipo de 30 minutos. Hay que acordar la fecha de lanzamiento, repartir las tareas pendientes y elegir quién revisará el resultado. Destaca las decisiones que debemos tomar.

  3. Continúa la conversación

    Envía el mensaje con el botón de flecha. Al recibir la respuesta, ajusta la tarea; por ejemplo, pide que la reunión dure 20 minutos.
