Browser Control

Votre Chrome.
Les possibilités d'Ocean.

Lisez des pages, remplissez des formulaires et gérez les onglets depuis le chat. Vos connexions aux sites restent dans votre profil Chrome habituel.

Premiers pas

La connexion
en deux étapes

Dans Ocean, commencez par Plugins → Contrôle du navigateur.

  1. 01

    Installez l'extension

    Cliquez sur Installer l'extension dans Ocean et suivez les instructions dans Chrome.

  2. 02

    Connectez-vous à Ocean

    Revenez dans l'application et cliquez sur Se connecter. Choisissez ensuite les sites autorisés.

Vous fixez les limites

Des onglets sous votre contrôle

Ocean ouvre des onglets distincts pour chaque chat. Pour lui confier un onglet personnel déjà ouvert, utilisez le bouton de l'extension dans Chrome.

La connexion seule ne donne pas à Ocean accès à tous les sites. Vous pouvez modifier les autorisations dans l'application.
