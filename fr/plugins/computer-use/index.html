Computer Use

Vos applications.
L'aide d'Ocean.

Autorisez Ocean à lire les interfaces et à effectuer des tâches dans les applications nécessaires. Vous choisissez l'accès à chaque application.

01 Activer le plugin02 Configurer le système03 Tester dans le chat

Étape 01

Activez le plugin

Commencez dans la section Plugins de la barre latérale d'Ocean.

  1. Ouvrez Utilisation de l'ordinateur

    Activez l'interrupteur dans la fiche du plugin. Si Ocean demande un redémarrage, effectuez-le.

  2. Gardez la fiche ouverte

    Elle indique si le système est prêt et affiche les autorisations d'accès aux applications.

Si la fiche n'apparaît pas dans la liste, le plugin n'est pas encore installé. Contactez l'assistance — nous vous aiderons à l'installer sur votre système.

Étape 02

Préparez votre système

Choisissez votre système d'exploitation. Les fonctions du plugin varient selon la plateforme.

macOS
  1. Dans les lignes Accessibilité et Enregistrement de l'écran, cliquez sur Demander l'autorisation.
  2. Dans les réglages système, autorisez l'accès à l'application indiquée dans le panneau Ocean.
  3. Revenez dans Ocean. Les deux autorisations doivent afficher le statut Autorisé.

Une fois la configuration terminée, vous pouvez lire les interfaces, capturer les fenêtres, cliquer, saisir du texte et faire défiler le contenu.

Windows
  1. Lancez Ocean dans une session Windows normale, avec le bureau déverrouillé.
  2. Vérifiez Bureau interactif et Capture des fenêtres dans la fiche.
  3. Gardez l'application concernée au premier plan pour les actions à la souris et au clavier.

La lecture des interfaces, la capture des fenêtres et le contrôle sont disponibles. Les applications lancées en tant qu'administrateur peuvent refuser l'accès.

Si le composant natif est indisponible, contactez l'assistance pour le configurer sur votre système.

Linux
  1. Lancez Ocean dans votre session graphique locale et déverrouillez le bureau.
  2. Vérifiez la disponibilité d'AT-SPI dans la fiche. Python 3 du système, PyGObject et AT-SPI sont nécessaires ; le plugin ne les installe pas automatiquement.
  3. Ouvrez une application compatible avec AT-SPI.

La lecture des éléments d'interface et les actions exposées par l'application sont disponibles. Les captures d'écran, les entrées classiques à la souris et au clavier, ainsi que le lancement d'applications ne sont pas pris en charge.

Étape 03

Testez l'accès dans le chat

Pour commencer, lire une fenêtre suffit. Un modèle doit être connecté dans Ocean.

  1. Ouvrez l'application souhaitée

    Choisissez une fenêtre sans données personnelles, par exemple un éditeur de texte avec une note de test.

  2. Demandez à Ocean de regarder la fenêtre

    Lis la fenêtre ouverte de mon éditeur de texte et décris brièvement ce qui est visible. Ne modifie rien.

    Précisez le nom de votre éditeur si plusieurs applications sont ouvertes.

  3. Confirmez l'accès

    Ocean demandera l'autorisation d'accéder à l'application sélectionnée. Après confirmation, il lira les éléments disponibles et répondra dans le chat.

Vous contrôlez les accès

Arrêter ou révoquer

Cliquez sur Arrêter dans le chat pour interrompre le travail en cours. Dans la fiche du plugin, cliquez sur Révoquer à côté d'une application pour supprimer son autorisation.

La liste des applications se remplit après les demandes d'accès. Il est normal qu'elle soit vide avant la première tâche.
