Super Agent

Tableau des tâches

Un tableau de développement persistant : l'agent prend une tâche dans son propre arbre de travail Git, exécute les vérifications du dépôt et renvoie le résultat.

Le travail survit à la session : le tableau reste, et l'exécuteur mène la tâche jusqu'à un résultat vérifié.

Agent Developer Patterns

Patrons de développement d'agents

Une compétence répartitrice : elle nomme la phase en cours et fournit une procédure prête — plan, entretien, TDD, débogage par hypothèses, revue ou passation.

Fonctionne depuis le paquet lui-même ; les jeux de compétences supplémentaires sont facultatifs.

Remotion studio

Studio de vidéos

Créez un projet Remotion à partir d'un modèle, prévisualisez-le dans Studio et rendez un MP4 sans quitter la conversation.

Le rendu s'exécute en tâche de fond : un encodage long ne bloque pas la conversation.
