La transparence sur les données

Vos données dans Ocean

Les chats sont enregistrés sur votre ordinateur. Pour obtenir une réponse, Ocean transmet le contexte au modèle choisi, tandis que les outils connectés contactent les services nécessaires à la tâche.

Sur votre appareil

Historique des chats, paramètres et connexions enregistrées.

Chez le fournisseur du modèle

Messages et documents inclus dans la requête.

Sous votre contrôle

Le choix du modèle, des plugins, des sites et des applications.

Ce qui est stocké localement

En mode bureau standard, Ocean conserve l'historique des messages et des actions des outils, les pièces jointes, les paramètres et les données de connexion dans le dossier de données de l'application. Par défaut, il s'agit de ~/.ocean; cet emplacement peut être modifié dans une configuration personnalisée.

Les clés API et les données d'autorisation sont conservées séparément du texte des paramètres. La protection des fichiers locaux dépend de l'accès à votre ordinateur : ce stockage n'est pas isolé de tous les outils de l'agent.

Ce que reçoit le modèle

La requête est envoyée au fournisseur que vous avez connecté. Elle peut contenir les messages du chat, les fichiers lus pour la tâche, le texte des pages, des captures de fenêtres et les résultats des outils. Le stockage local de l'historique ne signifie pas que le traitement par le modèle s'effectue également en local.

La durée de conservation et l'utilisation des données chez le fournisseur sont régies par ses conditions et les paramètres de votre compte. Les services de recherche, outils externes et plugins tiers ont également leurs propres règles de traitement des données.

Navigateur et applications

Choisissez les sites et applications autorisés dans les paramètres du plugin concerné. Les captures et les contenus lus peuvent être intégrés au chat et à la requête au modèle. Vous pouvez révoquer l'accès et désactiver le plugin.

Les autorisations, l'association et le stockage des données de l'extension Chrome sont décrits séparément : confidentialité de Browser Control.

Envoi des journaux et diagnostics

Lorsque vous utilisez l'adaptateur DeepSeek, un paramètre distinct intitulé « Envoyer le journal avec les requêtes API DeepSeek » se trouve dans Paramètres → Général. Il est activé dans la configuration par défaut : le journal du chat, messages et résultats des outils compris, est ajouté à la requête API. Sa réactivation peut aussi envoyer les entrées accumulées précédemment.

L'envoi séparé de journaux à un service de télémétrie est désactivé dans la configuration par défaut d'Ocean. L'analyse de l'utilisation du produit nécessite un destinataire explicitement configuré et une activation distincte.

L'adaptateur DeepSeek transmet également un identifiant d'installation aléatoire, conservé entre les lancements. Cela ne dépend pas du paramètre de télémétrie.

Si vous utilisez une configuration personnalisée

La configuration peut inclure d'autres destinataires de données. Lorsqu'il est activé, le mécanisme intégré d'envoi de commentaires transmet le journal jusqu'au moment du commentaire, contexte compris. Vérifiez les paramètres de votre installation et des fournisseurs connectés.

Comment gérer les données enregistrées

L'archivage masque un chat dans la liste principale, mais ne supprime pas son journal. Supprimer un espace de travail ne supprime pas non plus son dossier ni l'historique de ses chats.

Pour supprimer toutes les données locales d'Ocean, fermez d'abord l'application et sauvegardez les résultats utiles, puis supprimez le dossier de données de l'application. Les chats locaux, paramètres et connexions enregistrées de tous les profils de ce dossier seront également supprimés. Si vous utilisez un emplacement de données personnalisé, faites confirmer le chemin par l'assistanceavant de supprimer des fichiers.

Cela ne supprime pas vos fichiers de projet, sauvegardes externes, données de l'extension Chrome ni documents déjà transmis aux fournisseurs. Gérez-les dans l'application ou le service concerné.

Ce que fait ce site

Le site ne contient ni formulaire d'inscription, ni traceur publicitaire, ni outil de mesure tiers intégré. Les polices et images sont chargées depuis le domaine Ocean. La page de téléchargement demande à GitHub la liste des fichiers publiés.

Le site est hébergé sur GitHub Pages. Lorsque vous accédez au site, à GitHub ou à des liens externes, les services concernés reçoivent les données habituelles d'une requête réseau. Les règles de GitHub sont décrites dans sa politique de confidentialité.

Questions sur les données

Contactez l'assistance Ocean ou écrivez à support@oceanharness.com. Ne joignez pas de clés API, de mots de passe ni de journal de chat complet sans nécessité.
