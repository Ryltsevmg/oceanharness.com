Installez Ocean, connectez un modèle et lancez la conversation. Vous pourrez ajouter le navigateur et les applications plus tard.

01 Installer Ocean 02 Connecter un modèle 03 Donner une tâche

Étape 01

Installez Ocean

Sur la page de téléchargement, choisissez votre système et votre architecture.

Choisir un téléchargement ↓
macOS
  1. Ouvrez le DMG ou décompressez le ZIP téléchargé.
  2. Déplacez l'application Ocean dans le dossier Applications.
  3. Lancez Ocean depuis ce dossier.

Apple silicon convient aux puces Apple M. Le type de processeur est indiqué dans le menu Apple → À propos de ce Mac.

Windows
  1. Téléchargez le programme d'installation lorsqu'il est disponible pour votre système.
  2. Ouvrez le fichier et suivez les étapes d'installation.
  3. Lancez Ocean depuis le menu Démarrer.
Linux
  1. Décompressez l'archive TAR.GZ dans un dossier distinct.
  2. Gardez tous les fichiers de l'archive ensemble.
  3. Ouvrez un terminal dans le dossier décompressé et lancez ./ocean.

La commande uname -m vous aide à choisir l'architecture : x86_64 — x64, aarch64 — ARM64.

Étape 02

Connectez votre modèle

Pour la première conversation, un fournisseur et sa clé API suffisent.

  1. Ouvrez Paramètres → Modèles

    Cliquez sur Ajouter un fournisseur de modèles et choisissez un fournisseur dans le catalogue. S'il est déjà dans la liste, ouvrez Modifier.

  2. Ajoutez une clé API

    Récupérez la clé dans l'espace de votre fournisseur, collez-la dans le champ Clé API et cliquez sur Appliquer.

  3. Vérifiez que la clé est enregistrée

    La mention Clé API configurée apparaîtra pour le fournisseur. Le premier message permettra de vérifier le fonctionnement du modèle.

L'accès aux modèles et le prix des requêtes dépendent de votre fournisseur. Si vous connectez un compte via un plugin, l'authentification se fait dans la fiche de ce plugin.

Étape 03

Obtenez votre première réponse

Commencez par une petite tâche. Cet exemple ne nécessite aucun accès au navigateur ou aux applications.

  1. Créez un chat

    Cliquez sur Nouvelle session dans le panneau de gauche. Sous le champ de message, choisissez le modèle connecté.

  2. Décrivez la tâche

    Essayez l'exemple de la page d'accueil. Il contient déjà tout le contexte nécessaire :

    Prépare un ordre du jour pour une réunion d'équipe de 30 minutes. Il faut convenir de la date de lancement, répartir les tâches restantes et choisir qui vérifiera le résultat. Fais ressortir les décisions à prendre.

  3. Poursuivez la conversation

    Envoyez le message avec le bouton en forme de flèche. Après la réponse, précisez la tâche — demandez par exemple de faire tenir la réunion en 20 minutes.

Si aucune réponse n'arrive

Vérifiez le modèle sélectionné, la clé API et le solde disponible dans l'espace de votre fournisseur. Si Ocean affiche une erreur, contactez l'assistance et joignez son texte sans clé ni mot de passe.
