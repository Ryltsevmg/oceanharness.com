Ocean

An independent desktop workspace for AI agents, conversations and tools. All-plugin harness, durable sessions, macOS and Linux.

Download for macOS (Apple silicon) Source and releases

  • Self-updating desktop client with signed, notarized macOS builds.
  • Plugin manager with optional on-demand bundles.
  • Durable session logs with recorded-session replay tests.
Desktop updates are served from https://update.oceanharness.com/dsh-desk/feeds/<target>/<channel>.yml. Linux builds ship as unsigned archives with an offline-signed release manifest.
