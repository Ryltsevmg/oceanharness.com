04 / 潜る前に

始める前の
よくある質問。

モデルのサブスクリプションは必要ですか？

ご自身のアカウントまたは API キーを接続してください。利用できるモデルや料金は、選択したプロバイダーによって異なります。

インストール後は何から始めればよいですか？

「設定 → モデル」でプロバイダーを追加し、最初のセッションを作成します。 手順に沿って設定する.
