Browser Control のプライバシー

2026年11月16日施行。このポリシーは、Chrome 向け Ocean Browser Control 拡張機能に適用されます。アプリ自体のチャット保存とデータ処理については、次のページをご覧ください： 「Ocean でのあなたのデータ」.

拡張機能の役割

この拡張機能は Chrome をペアリング済みの中継サービスに接続し、Ocean がタスク用のタブや、ブラウザのツールバーボタンから渡されたタブを操作できるようにします。Ocean には、アクセスを許可するサイトの専用設定があります。Chrome の権限はこの設定より広いため、制限は独立した Chrome サンドボックスではなく、アプリのレベルで適用されます。

処理するデータ

拡張機能はリクエストに応じて、ページのテキストや構造、URL、タブのタイトル、スクリーンショット、入力欄の値を読み取り、要素のクリック、文字入力、タブの操作を行えます。ページには、個人情報、認証情報、金融・医療情報などの機密性の高い情報が含まれる場合があります。中継サービスは、リクエストに応じた、渡されたタブの録画にも対応しています。サイトへのログイン状態は Chrome プロファイルに保持され、通常のブラウザセッションを通じて使用されます。

データの送信先

既定では、拡張機能はお使いのパソコン上の中継サービスとコマンドや結果をやり取りします。詳細設定では、別のパソコン上にある任意のサービスを指定できます。信頼できるサービスとネットワークだけを使用してください。Ocean は、タスク用に選択されたモデルプロバイダーにページ内容やスクリーンショットを送信する場合があります。その場合、プロバイダーの利用規約とプライバシーポリシーが適用されます。拡張機能自体がモデルプロバイダーを選ぶことはありません。

拡張機能には広告や分析のサービスはなく、ブラウザのデータを Ocean のデータ収集サーバーへ送信することもありません。ブラウザのデータは依頼された操作のために使われ、販売されたり、広告、プロファイリング、無関係な目的に使われたりすることはありません。データの利用と転送は、Chrome Web Store のユーザーデータに関するポリシーおよび Limited Use 要件に準拠します。

保存と削除

拡張機能は、ペアリング情報と設定を Chrome の拡張機能ストレージに保存します。中継サービスへのアクセス情報と Ocean のタスク記録は、別途保存されます。拡張機能を削除すると、そのローカルストレージも削除されます。ただし、Ocean のチャットログ、中継サービスのファイル、モデルプロバイダーへ送信済みのコピーは残ります。それぞれのアプリやサービスで管理してください。

Chrome の権限

  • debugger: Chrome DevTools Protocol を通じた、渡されたページの閲覧、スクリーンショット、ブラウザ操作。
  • tabs と tabGroups： タスク用のタブを管理し、エージェントのセッションごとにグループ化します。
  • storage: ペアリング情報と設定のローカル保存。
  • alarms: 拡張機能のバックグラウンドプロセスが停止した後、中継サービスに再接続します。
  • offscreen と tabCapture： リクエストに応じて、渡されたタブの録画を処理します。
  • webNavigation: ポップアップやページ遷移を、タスクのタブに関連付けます。
  • scripting: ページ操作のために、拡張機能に同梱された補助スクリプトを実行します。
  • notifications: タスクにあなたの操作が必要なときに通知します。
  • すべてのサイトへのアクセス： ユーザーが選択したサイトを操作し、設定されたサービスと通信します。拡張機能は、閲覧履歴データベース全体へのアクセスを要求しません。

あなたによる管理

Ocean でアクセスを許可するサイトを選び、既存のタブは明示的に渡してください。使用を停止するには、プラグインまたは拡張機能を無効にします。機密性の高い情報を含むページで操作する前に、タスクの内容を確認してください。選択したモデルプロバイダーに送信する意図がなければ、秘密情報をタスクに入力しないでください。
