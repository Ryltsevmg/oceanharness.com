Computer Use

いつものアプリ。
Ocean のサポート。

必要なアプリの画面を読み取り、タスクを実行できるよう Ocean に許可します。アプリごとのアクセスは、あなたが選べます。

01 プラグインを有効にする02 システムを設定03 チャットで確認

ステップ 01

プラグインを有効にする

Ocean のサイドバーにある「プラグイン」から始めてください。

  1. 「コンピューターの使用」を開く

    プラグインカードのスイッチをオンにします。Ocean に再起動を求められたら、再起動してください。

  2. カードを開いたままにする

    システムの準備状況と、アプリへのアクセス権が表示されます。

一覧にカードがない場合、プラグインはまだインストールされていません。 サポートにお問い合わせください 。お使いの OS へのインストールをお手伝いします。

ステップ 02

システムを準備する

お使いの OS を選んでください。プラグインの機能はプラットフォームによって異なります。

macOS
  1. 「アクセシビリティ」と「画面収録」の行で「権限をリクエスト」をクリックしてください。
  2. システム設定で、Ocean のパネルに表示されているアプリへのアクセスを許可します。
  3. Ocean に戻ります。両方の権限が「許可済み」と表示されることを確認してください。

設定後は、画面の読み取り、ウィンドウ撮影、クリック、文字入力、スクロールが使えます。

Windows
  1. デスクトップのロックを解除し、通常の Windows セッションで Ocean を起動してください。
  2. カードで「対話型デスクトップ」と「ウィンドウキャプチャ」を確認してください。
  3. マウスやキーボードの操作時は、対象のアプリを最前面にしてください。

画面の読み取り、ウィンドウ撮影、操作が利用できます。管理者権限で実行中のアプリは、アクセスを拒否する場合があります。

ネイティブコンポーネントが利用できない場合は、 サポートにお問い合わせください 。お使いの OS に合わせた設定をお手伝いします。

Linux
  1. ローカルのグラフィカルセッションで Ocean を起動し、デスクトップのロックを解除してください。
  2. カードで AT-SPI が利用可能か確認してください。システムの Python 3、PyGObject、AT-SPI が必要です。プラグインはこれらを自動でインストールしません。
  3. AT-SPI に対応したアプリを開いてください。

UI 要素の読み取りと、アプリ自体が提供する操作が利用できます。スクリーンショット、通常のマウス・キーボード入力、アプリの起動には対応していません。

ステップ 03

チャットでアクセスを確認

最初はウィンドウの読み取りだけで十分です。事前に Ocean でモデルを接続してください.

  1. 対象のアプリを開く

    個人情報のないウィンドウを選びます。たとえば、テスト用のメモを開いたテキストエディターなどです。

  2. Ocean にウィンドウの確認を依頼

    開いているテキストエディターのウィンドウを読み取って、見えている内容を簡潔に説明して。何も変更しないで。

    複数のアプリを開いている場合は、エディターの名前を指定してください。

  3. アクセスを許可

    Ocean が選択したアプリへのアクセス許可を求めます。許可すると、読み取り可能な要素を確認し、チャットで回答します。

アクセスを管理する

停止または権限の取り消し

現在の作業を中断するには、チャットの「停止」をクリックします。アクセス権を取り消すには、プラグインカードでアプリの横にある「取り消す」をクリックしてください。

アプリ一覧はアクセス要求の後に表示されます。最初のタスクの前は空でも問題ありません。
