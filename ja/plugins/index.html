いつも使っているブラウザやアプリを接続しましょう。

Browser Control

ブラウザの操作

いつもの Chrome を、ログイン状態を保ったまま。チャットからページを読み、フォームに入力し、タブを操作できます。

アクセスを許可するサイトを選べます。すでに開いているタブを Ocean に渡すこともできます。

Computer Use

アプリの操作

許可したアプリの画面の読み取り、ウィンドウ撮影、クリック、文字入力、スクロール。

Ocean の「プラグイン」でアクセスを設定してください。利用できる操作は OS によって異なります。

接続方法 →

Super Agent

タスクボード

永続的な開発ボード: エージェントは専用の git ワークツリーで課題を引き受け、リポジトリのチェックを実行して結果を返します。

作業はセッションより長く残ります。ボードはそのままに、実行者が検証済みの結果まで導きます。

Agent Developer Patterns

エージェント開発パターン

ディスパッチャー型スキル: 現在のフェーズを判定し、すぐに使える手順を 1 つ渡します — 計画、インタビュー、TDD、仮説駆動のデバッグ、レビュー、ハンドオフ。

バンドルだけで動作し、追加のスキルセットは任意です。

Remotion studio

リールスタジオ

テンプレートから Remotion プロジェクトを作成し、Studio でプレビューして、会話を離れずに MP4 をレンダリングします。

レンダリングはバックグラウンドジョブで実行されるため、長いエンコードでもチャットを妨げません。

Theme picker

インターフェーステーマ

27 種類のパレット: Abyss、One Dark/Light、Dracula/Alucard、GitHub、Solarized、Nord、Tokyo Night、Catppuccin、Gruvbox、Everforest、Rosé Pine、Kanagawa、Ayu、Night Owl、Material、Flexoki、Modus、Darcula、Mariana、Oxocarbon、PaperColor、Seoul256、Monokai、SynthWave '84、Cobalt2、Horizon、Jellybeans。

1 つの選択バンドルがライトとダークの両方で画面を塗り替え、「外観」設定はそのままです。

Ocean の機能

エージェントチーム
