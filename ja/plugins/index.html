ブラウザの操作

Computer Use

アプリの操作

許可したアプリの画面の読み取り、ウィンドウ撮影、クリック、文字入力、スクロール。

接続方法 →

Codex

ChatGPT アカウント

ChatGPT Plan をネイティブのプロバイダーとして: OAuth でログインし、アカウントのモデルカタログを読み込みます。

Super Agent

タスクボード

課題はセッションより長く残ります。実行役が専用の git ワークツリーで引き受け、検証済みの結果まで進めます。

Agent Developer Patterns

エージェント開発パターン

ディスパッチャー型スキル: 課題のフェーズを判定して、すぐに使える手順を 1 つ渡します — 計画、インタビュー、TDD、デバッグ、レビュー、ハンドオフ。

Remotion studio

リールスタジオ

テンプレートから Remotion プロジェクトを作成し、Studio でプレビューして、会話を離れずに MP4 をレンダリングします。

Theme picker

インターフェーステーマ

Abyss や One Dark から Catppuccin、Gruvbox、Monokai まで 27 種類のパレット。両方のインターフェーススキームで使えます。

Forge

変更リクエスト

git リポジトリのセッションが専用のワークツリーと変更リクエストのパネルを持ち、GitHub は CLI 経由で扱います。

Auto review

自動レビュー

Auto プリセットでは、ループを進める前に各ツール呼び出しを利用者の要求と突き合わせます。

Developer tools

開発者ツール

セッションと Chat ノードのインスペクター、ターンごとのコンテキストとコストの統計、明示的にオンにする CDP ハブ。

Voice input

音声入力

ローカルの SenseVoice ランタイムによるディクテーション。音声は端末内に留まり、モデルの重みは初回利用時にダウンロードされます。

Session titles

セッションタイトル

セッション名は最初のメッセージだけでなく、その後のやり取りにも追随します。

Ocean の機能

エージェントチーム

タスクを分担し、全体の進捗を把握できます。

自分のワークスペースを作ろう

アプリの「プラグイン」でツールや接続を管理できます。
