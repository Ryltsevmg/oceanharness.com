データの取り扱いを明確に

Ocean でのあなたのデータ

チャットはお使いのパソコンに保存されます。回答の生成時に、Ocean は選択したモデルへコンテキストを送り、接続されたツールはタスクに必要なサービスにアクセスします。

リクエストに含まれるメッセージや資料。

モデル、プラグイン、サイト、アプリの選択。

ローカルに保存されるもの

通常のデスクトップモードでは、Ocean はメッセージとツール操作の履歴、添付ファイル、設定、接続情報をアプリのデータフォルダに保存します。既定の場所は ~/.oceanです。独自の設定で保存先を変更できます。

API キーと認証情報は設定テキストとは別に保存されます。ローカルファイルの保護は、パソコンへのアクセス管理に依存します。この保存領域は、エージェントのすべてのツールから隔離されているわけではありません。

モデルに送られるもの

リクエストは、接続したプロバイダーに送信されます。チャットのメッセージ、タスクのために読み取ったファイル、ページのテキスト、ウィンドウの画像、ツールの結果が含まれる場合があります。履歴をローカルに保存していても、モデルによる処理がローカルで行われるとは限りません。

プロバイダー側でのデータの保存期間や利用方法は、その利用規約とアカウント設定によって決まります。検索サービス、外部ツール、サードパーティーのプラグインにも、それぞれのデータ取り扱い規則があります。

ブラウザとアプリ

各プラグインの設定で、アクセスを許可するサイトやアプリを選んでください。画像や読み取った内容は、チャットやモデルへのリクエストに含まれる場合があります。アクセス権は取り消せますし、プラグインを無効にすることもできます。

Chrome 拡張機能の権限、ペアリング、データ保存については、別のページで説明しています： Browser Control のプライバシー.

ログの送信と診断

DeepSeek アダプターを利用する場合は、 「DeepSeek API リクエストにログを添付」 という専用設定が「設定 → 一般」にあります。基本設定では有効になっており、メッセージやツールの結果を含むチャットログが API リクエストに添付されます。再び有効にすると、過去に蓄積された記録も送信される場合があります。

Ocean の基本設定では、テレメトリーサービスへのログの個別送信は無効です。製品分析には送信先の明示的な設定と、別途有効化が必要です。

DeepSeek アダプターは、起動をまたいで保持されるランダムなインストール識別子も送信します。これはテレメトリーの設定とは無関係です。

独自の設定を使う場合

設定によっては、別のデータ送信先が含まれます。組み込みのフィードバック送信機能を有効にすると、コンテキストを含む、フィードバック時点までのログが送信されます。お使いのビルドと接続先プロバイダーの設定を確認してください。

保存データの管理方法

アーカイブするとチャットはメインの一覧から非表示になりますが、ログは削除されません。ワークスペースを削除しても、そのフォルダやチャット履歴は削除されません。

Ocean のローカルデータをすべて削除するには、まずアプリを終了して必要な結果を保存し、その後アプリのデータフォルダを削除します。そのフォルダ内のすべてのプロファイルのローカルチャット、設定、保存済み接続情報も削除されます。保存先を変更している場合は、ファイルを削除する前に サポートにパスをご確認ください。

プロジェクトのファイル、外部のバックアップ、Chrome 拡張機能のデータ、すでにプロバイダーへ送信された資料は削除されません。それぞれのアプリやサービスで管理してください。

このサイトについて

このサイトには、登録フォーム、広告トラッカー、埋め込みのサードパーティー解析ツールはありません。フォントと画像は Ocean のドメインから読み込まれます。ダウンロードページは、公開ファイルの一覧を GitHub から取得します。

このサイトは GitHub Pages でホスティングされています。サイトや GitHub、外部リンクにアクセスすると、各サービスは通常のネットワークリクエストのデータを受け取ります。GitHub の規則については、次をご覧ください： GitHub のプライバシーに関する声明.
