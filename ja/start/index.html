最初のタスクへ。

Ocean をインストールし、モデルを接続して会話を始めましょう。ブラウザやアプリは、あとから追加できます。

01 Ocean をインストール 02 モデルを接続 03 タスクを伝える

ステップ 01

Ocean をインストール

ダウンロードページで OS とアーキテクチャを選びます。

ダウンロードを選ぶ ↓
macOS
  1. DMG を開くか、ダウンロードした ZIP を展開します。
  2. Ocean アプリを「アプリケーション」フォルダに移動します。
  3. そのフォルダから Ocean を起動します。

Apple M チップには Apple silicon を選びます。プロセッサの種類は Apple メニュー →「この Mac について」で確認できます。

Windows
  1. お使いの OS 向けのインストーラーが提供されていれば、ダウンロードします。
  2. ファイルを開き、インストールの手順に従います。
  3. 「スタート」メニューから Ocean を起動します。
Linux
  1. TAR.GZ アーカイブを専用のフォルダに展開します。
  2. アーカイブ内のすべてのファイルを、まとめて同じ場所に置いてください。
  3. 展開したフォルダでターミナルを開き、次を実行します： ./ocean.

次のコマンドで確認できます： uname -m 結果からアーキテクチャを選びます： x86_64 — x64, aarch64 — ARM64.

ステップ 02

使いたいモデルを接続

最初の会話には、プロバイダー 1 社とその API キーがあれば十分です。

  1. 「設定」→「モデル」を開く

    「モデルプロバイダーを追加」をクリックし、カタログから選びます。すでに一覧にある場合は、「編集」を開いてください。

  2. API キーを追加

    プロバイダーの管理画面でキーを取得し、「API キー」欄に貼り付けて「適用」をクリックします。

  3. キーが保存されたことを確認

    プロバイダーに「API キー設定済み」と表示されます。最初のメッセージでモデルの動作を確認しましょう。

利用できるモデルやリクエストの料金は、プロバイダーによって異なります。プラグイン経由でアカウントを接続する場合は、そのプラグインのカードでログインします。

ステップ 03

最初の回答を受け取る

小さなタスクから始めましょう。この例では、ブラウザやアプリへのアクセスは不要です。

  1. チャットを作成

    左側のパネルで「新しいセッション」をクリックし、メッセージ欄の下部で接続済みのモデルを選びます。

  2. タスクを説明

    トップページの例を試してみましょう。必要な情報はすべて含まれています：

    30 分間のチームミーティングの進行案を作って。公開日を決め、残りのタスクを分担し、結果の確認担当を決めたい。決めるべきことを明確にして。

  3. 会話を続ける

    矢印ボタンでメッセージを送信します。回答を受け取ったら、たとえば会議を 20 分に収めるよう頼むなど、タスクを調整してみましょう。

回答が届かない場合

選択したモデル、API キー、プロバイダーの管理画面の利用可能残高を確認してください。Ocean にエラーが表示された場合は、 サポートにお問い合わせください 。キーやパスワードを含めずに、エラーメッセージをお知らせください。
