채팅으로 페이지를 읽고, 양식을 작성하고, 탭을 관리하세요. 사이트 로그인 상태는 평소 사용하는 Chrome 프로필에 유지됩니다.

시작하기

연결은
두 단계로

Ocean의 ‘플러그인’ → ‘브라우저 제어’에서 시작하세요.

  1. 01

    확장 프로그램 설치

    Ocean에서 ‘확장 프로그램 설치’를 누르고 Chrome의 안내를 따르세요.

  2. 02

    Ocean에 연결

    앱으로 돌아와 ‘연결’을 누른 뒤 접근을 허용할 사이트를 선택하세요.

범위는 직접 결정

직접 관리하는 탭

Ocean은 채팅마다 별도의 탭을 엽니다. 이미 열려 있는 개인 탭을 넘기려면 Chrome의 확장 프로그램 버튼을 사용하세요.

연결만으로 Ocean이 모든 사이트에 접근할 수 있는 것은 아닙니다. 권한은 앱에서 변경할 수 있습니다.
