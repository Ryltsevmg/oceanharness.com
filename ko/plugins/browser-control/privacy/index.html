Browser Control 개인정보 보호

2026년 11월 16일부터 시행됩니다. 이 정책은 Ocean Browser Control Chrome 확장 프로그램에 적용됩니다. 앱 자체의 채팅 저장 및 데이터 처리는 다음 페이지에서 확인할 수 있습니다: ‘Ocean의 내 데이터’.

확장 프로그램의 기능

확장 프로그램은 Chrome을 페어링된 중계 서비스에 연결하여 Ocean이 작업용 탭과 브라우저 도구 모음 버튼으로 넘겨받은 탭을 제어할 수 있게 합니다. Ocean에는 허용된 사이트를 지정하는 별도 설정이 있습니다. Chrome 권한은 이 설정보다 범위가 넓습니다. 제한은 별도의 Chrome 샌드박스가 아니라 앱 수준에서 적용됩니다.

처리하는 데이터

요청에 따라 확장 프로그램은 페이지 텍스트와 구조, URL, 탭 제목, 스크린샷, 필드 값을 읽고, 요소를 클릭하고, 텍스트를 입력하고, 탭을 관리할 수 있습니다. 페이지에는 개인정보, 인증 정보, 금융·의료 정보 및 기타 민감한 정보가 포함될 수 있습니다. 중계 서비스는 요청에 따라 넘겨받은 탭을 녹화하는 기능도 지원합니다. 사이트 로그인 상태는 Chrome 프로필에 유지되며 일반 브라우저 세션을 통해 사용됩니다.

데이터 전송 대상

기본적으로 확장 프로그램은 내 컴퓨터의 중계 서비스와 명령 및 결과를 주고받습니다. 고급 설정에서 다른 컴퓨터에 있는 원하는 서비스를 지정할 수 있습니다. 신뢰할 수 있는 서비스와 네트워크만 사용하세요. Ocean은 작업에 선택된 모델 제공업체로 페이지 내용과 스크린샷을 전송할 수 있습니다. 이 경우 해당 제공업체의 약관 및 개인정보 처리방침이 적용됩니다. 확장 프로그램 자체가 모델 제공업체를 선택하지는 않습니다.

확장 프로그램에는 광고나 분석 서비스가 없으며, 브라우저 데이터를 Ocean 데이터 수집 서버로 전송하지 않습니다. 브라우저 데이터는 요청된 동작에 사용되며, 판매되거나 광고, 프로파일링, 관련 없는 목적으로 사용되지 않습니다. 데이터 사용과 전송은 Chrome Web Store 사용자 데이터 정책 및 Limited Use 요건을 따릅니다.

저장 및 삭제

확장 프로그램은 페어링 정보와 설정을 Chrome 확장 프로그램 저장소에 저장합니다. 중계 서비스 접근 정보와 Ocean 작업 기록은 별도로 저장됩니다. 확장 프로그램을 삭제하면 해당 로컬 저장소가 삭제됩니다. 단, Ocean 채팅 로그, 중계 서비스 파일, 이미 모델 제공업체에 전송된 사본은 남으며 해당 앱이나 서비스에서 별도로 관리해야 합니다.

Chrome 권한

  • debugger: Chrome DevTools Protocol을 통해 넘겨받은 페이지를 보고, 스크린샷을 촬영하고, 브라우저를 조작합니다.
  • tabs 및 tabGroups: 작업용 탭을 관리하고 에이전트 세션별로 그룹화합니다.
  • storage: 페어링 정보와 설정을 로컬에 저장합니다.
  • alarms: 확장 프로그램의 백그라운드 프로세스가 일시 중지된 후 중계 서비스에 다시 연결합니다.
  • offscreen 및 tabCapture: 요청에 따라 넘겨받은 탭의 녹화를 처리합니다.
  • webNavigation: 팝업 창과 탐색을 작업용 탭에 연결합니다.
  • scripting: 페이지 작업을 위해 확장 프로그램에 포함된 보조 스크립트를 실행합니다.
  • notifications: 작업에 사용자 참여가 필요할 때 알립니다.
  • 모든 사이트 접근: 사용자가 선택한 사이트를 사용하고 설정된 서비스와 통신합니다. 확장 프로그램은 전체 방문 기록 데이터베이스에 대한 접근을 요청하지 않습니다.

사용자의 제어권

Ocean에서 허용할 사이트를 선택하고 기존 탭을 명시적으로 넘기세요. 사용을 중단하려면 플러그인이나 확장 프로그램을 끄세요. 민감한 데이터가 있는 페이지에서 조작하기 전에 작업을 확인하세요. 선택한 모델 제공업체에 전달할 의도가 없다면 작업에 비밀 정보를 입력하지 마세요.

연락처

개인정보 보호에 관한 질문이나 데이터 관련 요청은 support@oceanharness.com 또는 Ocean 지원팀로 보내 주세요. 정책이 변경되면 새로운 시행일과 함께 이 페이지에 게시됩니다.
