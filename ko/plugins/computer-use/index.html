Computer Use

내 앱.
Ocean의 도움.

Ocean이 필요한 앱의 인터페이스를 읽고 작업을 수행하도록 허용하세요. 각 앱의 접근 권한은 직접 결정합니다.

01 플러그인 켜기02 시스템 설정03 채팅에서 확인

1단계

플러그인 켜기

Ocean 사이드바의 ‘플러그인’에서 시작하세요.

  1. ‘컴퓨터 사용’ 열기

    플러그인 카드의 스위치를 켜세요. Ocean에서 재시작을 요청하면 재시작하세요.

  2. 카드를 열어 두기

    시스템 준비 상태와 앱 접근 권한이 여기에 표시됩니다.

목록에 카드가 없다면 플러그인이 아직 설치되지 않은 상태입니다. 지원팀에 문의하세요 . 운영체제에 맞는 설치를 도와드리겠습니다.

2단계

시스템 준비

운영체제를 선택하세요. 플러그인의 기능은 플랫폼마다 다릅니다.

macOS
  1. ‘손쉬운 사용’과 ‘화면 기록’ 항목에서 ‘권한 요청’을 누르세요.
  2. 시스템 설정에서 Ocean 패널에 표시된 앱의 접근을 허용하세요.
  3. Ocean으로 돌아오세요. 두 권한 모두 ‘허용됨’으로 표시되어야 합니다.

설정 후에는 인터페이스 읽기, 창 캡처, 클릭, 텍스트 입력, 스크롤을 사용할 수 있습니다.

Windows
  1. 데스크톱 잠금을 해제한 일반 Windows 세션에서 Ocean을 실행하세요.
  2. 카드에서 ‘대화형 데스크톱’과 ‘창 캡처’를 확인하세요.
  3. 마우스와 키보드로 조작할 때는 대상 앱을 맨 앞에 두세요.

인터페이스 읽기, 창 캡처, 제어를 사용할 수 있습니다. 관리자 권한으로 실행한 앱은 접근을 거부할 수 있습니다.

네이티브 구성 요소를 사용할 수 없다면 지원팀에 문의하세요 . 운영체제에 맞는 설정을 도와드리겠습니다.

Linux
  1. 로컬 그래픽 세션에서 Ocean을 실행하고 데스크톱 잠금을 해제하세요.
  2. 카드에서 AT-SPI 사용 가능 여부를 확인하세요. 시스템 Python 3, PyGObject, AT-SPI가 필요하며 플러그인이 자동으로 설치하지는 않습니다.
  3. AT-SPI를 지원하는 앱을 여세요.

인터페이스 요소 읽기와 앱 자체에서 제공하는 동작을 사용할 수 있습니다. 스크린샷, 일반 마우스·키보드 입력, 앱 실행은 지원하지 않습니다.

3단계

채팅에서 접근 확인

먼저 창을 읽어 보는 것으로 충분합니다. 사전에 Ocean에서 모델을 연결하세요.

  1. 대상 앱 열기

    개인정보가 없는 창을 선택하세요. 예를 들어 테스트 메모를 연 텍스트 편집기가 좋습니다.

  2. Ocean에 창 확인 요청하기

    열려 있는 텍스트 편집기 창을 읽고 보이는 내용을 간단히 설명해 줘. 아무것도 변경하지 마.

    앱이 여러 개 열려 있다면 편집기 이름을 알려 주세요.

  3. 접근 승인

    Ocean이 선택한 앱의 접근 권한을 요청합니다. 승인하면 접근 가능한 요소를 읽고 채팅으로 답합니다.

접근 권한은 직접 관리

중지 또는 권한 해제

채팅에서 ‘중지’를 누르면 진행 중인 작업을 멈출 수 있습니다. 플러그인 카드에서 앱 옆의 ‘권한 해제’를 누르면 해당 앱의 접근 권한이 취소됩니다.

앱 목록은 접근 요청 후에 채워집니다. 첫 작업 전에는 목록이 비어 있어도 정상입니다.
