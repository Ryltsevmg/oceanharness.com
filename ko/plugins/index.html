매일 사용하는 브라우저와 앱을 연결하세요.

Browser Control

브라우저 제어

로그인 상태를 유지한 채 내 Chrome을 사용하세요. 채팅으로 페이지를 읽고, 양식을 작성하고, 탭을 관리할 수 있습니다.

접근을 허용할 사이트를 직접 선택하고, 이미 열린 탭을 Ocean에 넘길 수도 있습니다.

연결 방법 →

Computer Use

앱 제어

허용한 앱에서 인터페이스 읽기, 창 캡처, 클릭, 텍스트 입력, 스크롤을 사용할 수 있습니다.

Ocean의 ‘플러그인’에서 접근 권한을 설정하세요. 사용 가능한 동작은 운영체제에 따라 다릅니다.

연결 방법 →

Super Agent

작업 보드

지속되는 개발 보드: 에이전트가 별도 git 워크트리에서 작업을 가져가 저장소 검사를 실행하고 결과를 보고합니다.

작업은 세션보다 오래 남습니다. 보드는 그대로 있고, 실행기가 검증된 결과까지 작업을 이끕니다.

Agent Developer Patterns

에이전트 개발 패턴

디스패처 스킬: 지금 어떤 단계인지 판별하고 바로 쓸 수 있는 절차 하나를 건넵니다 — 계획, 인터뷰, TDD, 가설 기반 디버깅, 리뷰 또는 핸드오프.

번들 자체로 동작하며 추가 스킬 세트는 선택 사항입니다.

Remotion studio

릴 스튜디오

템플릿에서 Remotion 프로젝트를 만들고 Studio에서 미리 본 뒤 대화를 떠나지 않고 MP4로 렌더링합니다.

렌더링은 백그라운드 작업으로 실행되므로 긴 인코딩이 채팅을 막지 않습니다.

Theme picker

인터페이스 테마

스물일곱 가지 팔레트: Abyss, One Dark/Light, Dracula/Alucard, GitHub, Solarized, Nord, Tokyo Night, Catppuccin, Gruvbox, Everforest, Rosé Pine, Kanagawa, Ayu, Night Owl, Material, Flexoki, Modus, Darcula, Mariana, Oxocarbon, PaperColor, Seoul256, Monokai, SynthWave '84, Cobalt2, Horizon, Jellybeans.

선택기 번들 하나가 라이트와 다크 두 체계에서 인터페이스를 다시 칠하며 「모양」 설정은 그대로 둡니다.
