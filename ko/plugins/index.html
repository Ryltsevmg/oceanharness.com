Codex

ChatGPT 계정

ChatGPT Plan을 네이티브 제공업체로 연결하세요. OAuth 로그인과 계정 모델 카탈로그를 제공합니다.

Super Agent

작업 보드

작업은 세션보다 오래 남습니다. 실행자가 별도 git 워크트리에서 맡아 검증된 결과까지 마칩니다.

Agent Developer Patterns

에이전트 개발 패턴

디스패처 스킬: 작업의 단계를 판별하고 바로 쓸 수 있는 절차 하나를 건넵니다 — 계획, 인터뷰, TDD, 디버깅, 리뷰 또는 핸드오프.

Remotion studio

릴 스튜디오

템플릿에서 Remotion 프로젝트를 만들고 Studio에서 미리 본 뒤 대화를 떠나지 않고 MP4로 렌더링합니다.

Theme picker

인터페이스 테마

Abyss와 One Dark부터 Catppuccin, Gruvbox, Monokai까지 27가지 팔레트 — 두 인터페이스 스킴 모두에서.

Forge

변경 요청

git 저장소의 세션이 자체 워크트리와 변경 요청 패널을 갖추고, GitHub는 CLI로 다룹니다.

Auto review

자동 리뷰

Auto 프리셋에서는 루프를 계속하기 전에 각 도구 호출을 요청과 대조합니다.

Developer tools

개발자 도구

세션과 Chat 노드 인스펙터, 턴별 맥락·비용 통계, 명시적으로 켜는 CDP 허브.

Voice input
