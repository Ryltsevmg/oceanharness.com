투명한 데이터 안내

Ocean의 내 데이터

채팅은 내 컴퓨터에 저장됩니다. 답변을 생성하기 위해 Ocean은 선택한 모델에 맥락을 전달하고, 연결된 도구는 작업에 필요한 서비스에 접근합니다.

기기에 저장

채팅 기록, 설정, 저장된 연결 정보.

모델 제공업체에 전달

요청에 포함된 메시지와 자료.

직접 관리

모델, 플러그인, 사이트, 앱 선택.

로컬에 저장되는 데이터

일반 데스크톱 모드에서 Ocean은 메시지 및 도구 동작 기록, 첨부 파일, 설정, 연결 정보를 앱 데이터 폴더에 저장합니다. 기본 위치는 ~/.ocean이며, 사용자 설정으로 위치를 변경할 수 있습니다.

API 키와 인증 정보는 설정 텍스트와 별도로 저장됩니다. 로컬 파일의 보호 수준은 컴퓨터 접근 권한에 달려 있습니다. 이 저장소가 에이전트의 모든 도구로부터 격리된 것은 아닙니다.

모델이 받는 데이터

요청은 연결한 제공업체로 전송됩니다. 채팅 메시지, 작업을 위해 읽은 파일, 페이지 텍스트, 창 캡처, 도구 결과가 포함될 수 있습니다. 기록이 로컬에 저장된다고 해서 모델 처리도 로컬에서 이루어지는 것은 아닙니다.

제공업체의 데이터 보관 기간과 사용 방식은 해당 약관 및 계정 설정에 따라 정해집니다. 검색 서비스, 외부 도구, 타사 플러그인에도 각각의 데이터 처리 규칙이 있습니다.

브라우저와 앱

각 플러그인 설정에서 접근을 허용할 사이트와 앱을 선택하세요. 캡처와 읽은 내용은 채팅 및 모델 요청에 포함될 수 있습니다. 접근 권한을 해제하거나 플러그인을 끌 수 있습니다.

Chrome 확장 프로그램의 권한, 페어링, 데이터 저장은 별도 페이지에서 설명합니다: Browser Control 개인정보 보호.

로그 전송 및 진단

DeepSeek 어댑터를 사용할 때는 ‘DeepSeek API 요청과 함께 로그 보내기’ 설정이 ‘설정 → 일반’에 있습니다. 기본 구성에서는 켜져 있으며, 메시지와 도구 결과를 포함한 채팅 로그가 API 요청에 첨부됩니다. 다시 켜면 이전에 쌓인 기록도 전송될 수 있습니다.

Ocean의 기본 구성에서는 텔레메트리 서비스로 로그를 별도 전송하는 기능이 꺼져 있습니다. 제품 분석은 수신 대상을 명시적으로 설정하고 별도로 켜야 합니다.

DeepSeek 어댑터는 실행 간에 유지되는 임의의 설치 식별자도 전송합니다. 이는 텔레메트리 설정과 무관합니다.

사용자 설정을 사용하는 경우

설정에 다른 데이터 수신 대상이 포함될 수 있습니다. 내장 피드백 전송 기능을 켜면 맥락을 포함해 피드백 시점까지의 로그가 전송됩니다. 사용 중인 빌드와 연결된 제공업체의 설정을 확인하세요.

저장된 데이터 관리 방법

보관 처리하면 채팅이 기본 목록에서 숨겨지지만 로그는 삭제되지 않습니다. 작업 공간을 삭제해도 해당 폴더와 채팅 기록은 삭제되지 않습니다.

Ocean의 모든 로컬 데이터를 삭제하려면 먼저 앱을 종료하고 필요한 결과를 저장한 다음 앱 데이터 폴더를 삭제하세요. 해당 폴더에 있는 모든 프로필의 로컬 채팅, 설정, 저장된 연결 정보도 함께 삭제됩니다. 데이터 저장 위치를 변경했다면 파일을 삭제하기 전에 지원팀에 경로를 확인하세요.

프로젝트 파일, 외부 백업, Chrome 확장 프로그램 데이터, 이미 제공업체에 전송된 자료는 삭제되지 않습니다. 해당 앱이나 서비스에서 별도로 관리해야 합니다.

이 사이트의 동작

이 사이트에는 가입 양식, 광고 추적기, 내장된 타사 방문 통계 도구가 없습니다. 글꼴과 이미지는 Ocean 도메인에서 불러옵니다. 다운로드 페이지는 GitHub에서 공개된 파일 목록을 가져옵니다.

이 사이트는 GitHub Pages에 호스팅됩니다. 사이트, GitHub, 외부 링크에 접근할 때 해당 서비스는 일반적인 네트워크 요청 정보를 받습니다. GitHub의 정책은 다음에서 확인할 수 있습니다: GitHub 개인정보 처리방침.

데이터 관련 문의

문의는 Ocean 지원팀 또는 support@oceanharness.com로 보내 주세요. 필요한 경우가 아니라면 API 키, 비밀번호, 전체 채팅 로그를 첨부하지 마세요.
