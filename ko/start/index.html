첫 잠수

첫 실행에서
첫 작업까지.

Ocean을 설치하고 모델을 연결해 대화를 시작하세요. 브라우저와 앱은 나중에 추가해도 됩니다.

01 Ocean 설치 02 모델 연결 03 작업 요청

1단계

Ocean 설치

다운로드 페이지에서 운영체제와 아키텍처를 선택하세요.

다운로드 선택 ↓
macOS
  1. DMG를 열거나 다운로드한 ZIP을 압축 해제하세요.
  2. Ocean 앱을 ‘응용 프로그램’ 폴더로 옮기세요.
  3. 해당 폴더에서 Ocean을 실행하세요.

Apple M 칩에는 Apple silicon을 선택하세요. 프로세서 종류는 Apple 메뉴 → ‘이 Mac에 관하여’에서 확인할 수 있습니다.

Windows
  1. 내 운영체제용 설치 프로그램이 제공되면 다운로드하세요.
  2. 파일을 열고 설치 단계를 진행하세요.
  3. ‘시작’ 메뉴에서 Ocean을 실행하세요.
Linux
  1. TAR.GZ 압축 파일을 별도 폴더에 압축 해제하세요.
  2. 압축 파일 안의 모든 파일을 함께 보관하세요.
  3. 압축 해제한 폴더에서 터미널을 열고 다음을 실행하세요: ./ocean.

다음 명령으로 확인할 수 있습니다: uname -m 출력 결과로 아키텍처를 선택하세요: x86_64 — x64, aarch64 — ARM64.

2단계

내 모델 연결

첫 대화에는 제공업체 하나와 해당 API 키면 충분합니다.

  1. ‘설정’ → ‘모델’ 열기

    ‘모델 제공업체 추가’를 누르고 목록에서 제공업체를 선택하세요. 이미 등록되어 있다면 ‘편집’을 여세요.

  2. API 키 추가

    제공업체 계정 페이지에서 키를 받아 ‘API 키’ 필드에 붙여 넣고 ‘적용’을 누르세요.

  3. 키 저장 확인

    제공업체에 ‘API 키 설정됨’이 표시됩니다. 첫 메시지로 모델이 작동하는지 확인하겠습니다.

이용 가능한 모델과 요청 비용은 제공업체에 따라 달라집니다. 플러그인으로 계정을 연결한다면 해당 플러그인 카드에서 로그인하세요.

3단계

첫 답변 받기

작은 작업부터 시작하세요. 이 예시에는 브라우저나 앱 접근 권한이 필요하지 않습니다.

  1. 채팅 만들기

    왼쪽 패널에서 ‘새 세션’을 누르고 메시지 입력란 아래에서 연결된 모델을 선택하세요.

  2. 작업 설명

    홈페이지의 예시를 사용해 보세요. 필요한 맥락이 모두 포함되어 있습니다:

    30분짜리 팀 회의 계획을 세워 줘. 출시 날짜를 정하고, 남은 작업을 분담하고, 결과를 확인할 사람을 정해야 해. 결정해야 할 사항을 정리해 줘.

  3. 대화 이어가기

    화살표 버튼으로 메시지를 보내세요. 답변을 받으면 회의를 20분으로 줄여 달라고 요청하는 등 작업을 구체화해 보세요.
