Browser Control

Ваш Chrome.
Возможности Ocean.

Читайте страницы, заполняйте формы и работайте с вкладками через чат. Входы на сайты сохраняются в вашем обычном профиле Chrome.

Начало работы

Подключение
в два шага

Начните в разделе «Плагины» → «Управление браузером» в Ocean.

  1. 01

    Установите расширение

    Нажмите «Установить расширение» в Ocean и следуйте инструкции в Chrome.

  2. 02

    Подключитесь к Ocean

    Вернитесь в приложение и нажмите «Подключиться». Затем выберите разрешённые сайты.

Вы задаёте границы

Вкладки под вашим контролем

Для каждого чата Ocean открывает отдельные вкладки. Чтобы передать уже открытую личную вкладку, используйте кнопку расширения в Chrome.

Подключение само по себе не даёт Ocean доступ ко всем сайтам. Разрешения можно изменить в приложении.
