Ваш Chrome в Ocean

Читайте страницы, заполняйте формы и работайте с вкладками через чат. Входы на сайты сохраняются в вашем обычном профиле Chrome.

Подключение

  1. В Ocean откройте «Плагины» → «Управление браузером» и нажмите «Установить расширение».
  2. После установки нажмите «Подключиться» в Ocean.

Выберите разрешённые сайты. Подключение само по себе не даёт Ocean доступ ко всем сайтам.

Вкладки под вашим контролем

Для каждого чата Ocean открывает отдельные вкладки. Чтобы передать уже открытую личную вкладку, используйте кнопку расширения в Chrome.

Расширение Ocean готовится к публикации в Chrome Web Store. Ссылка на него появится здесь после публикации.
