Computer Use

Ваши приложения.
Помощь Ocean.

Разрешите Ocean читать интерфейс и выполнять задачи в нужных приложениях. Доступ к каждому приложению выбираете вы.

01 Включить плагин02 Настроить систему03 Проверить в чате

Шаг 01

Включите плагин

Начните в разделе «Плагины» в боковой панели Ocean.

  1. Откройте «Использование компьютера»

    Включите переключатель в карточке плагина. Если Ocean попросит перезапуск, выполните его.

  2. Оставьте карточку открытой

    Здесь показана готовность системы и разрешения на доступ к приложениям.

Если карточки нет в списке, плагин ещё не установлен. Напишите в поддержку — поможем с установкой для вашей системы.

Шаг 02

Подготовьте систему

Выберите свою ОС. Возможности плагина различаются между платформами.

macOS
  1. В строках «Доступность» и «Запись экрана» нажмите «Запросить разрешение».
  2. В системных настройках разрешите доступ приложению, которое указано в панели Ocean.
  3. Вернитесь в Ocean. У обоих разрешений должен появиться статус «Разрешено».

После настройки доступны чтение интерфейса, снимки окон, нажатия, ввод текста и прокрутка.

Windows
  1. Запустите Ocean в обычном сеансе Windows с разблокированным рабочим столом.
  2. В карточке проверьте «Интерактивный рабочий стол» и «Захват окон».
  3. Для действий мышью и клавиатурой оставьте нужное приложение на переднем плане.

Доступны чтение интерфейса, снимки окон и управление. Приложения, запущенные от администратора, могут отказать в доступе.

Если нативный компонент недоступен, обратитесь в поддержку для его настройки под вашу систему.

Linux
  1. Запустите Ocean в своём локальном графическом сеансе и разблокируйте рабочий стол.
  2. В карточке проверьте доступность AT-SPI. Нужны системный Python 3, PyGObject и AT-SPI; плагин не устанавливает их автоматически.
  3. Откройте приложение с поддержкой AT-SPI.

Доступны чтение элементов интерфейса и действия, которые предоставляет само приложение. Снимки экрана, обычный ввод мышью и клавиатурой, запуск приложений не поддерживаются.

Шаг 03

Проверьте доступ в чате

Для начала достаточно прочитать окно. Модель должна быть подключена в Ocean.

  1. Откройте нужное приложение

    Выберите окно без личных данных — например, текстовый редактор с тестовой заметкой.

  2. Попросите Ocean посмотреть окно

    Прочитай открытое окно моего текстового редактора и кратко опиши, что в нём видно. Ничего не изменяй.

    Укажите название своего редактора, если открыто несколько приложений.

  3. Подтвердите доступ

    Ocean запросит разрешение на выбранное приложение. После подтверждения прочитает доступные элементы и ответит в чате.

Вы управляете доступом

Остановить или отозвать

Нажмите «Остановить» в чате, чтобы прервать текущую работу. В карточке плагина нажмите «Отозвать» рядом с приложением, чтобы убрать его разрешение.

Список приложений заполняется после запросов доступа. Пустой список до первой задачи — нормальное состояние.
