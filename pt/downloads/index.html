Guia do primeiro uso →
Qual arquitetura escolher?

No Mac, abra o menu Apple → «Sobre Este Mac»: chip Apple M corresponde a Apple silicon, e processador Intel, a Intel. No Windows, a arquitetura aparece em «Configurações → Sistema → Sobre». No Linux, o comando uname -m mostrará x86_64 para x64 ou aarch64 para ARM64.

Como instalar o Ocean?

No macOS, abra o DMG ou extraia o ZIP e mova o aplicativo para «Aplicativos». No Windows, execute o instalador baixado. No Linux, extraia o TAR.GZ, abra a pasta extraída no terminal e execute ./ocean. Se você baixou um AppImage, permita a execução nas propriedades do arquivo. Mais sobre a instalação.

O que preciso fazer após a instalação?

Abra «Configurações → Modelos» e clique em «Adicionar provedor de modelos». Insira os dados de conexão e clique em «Aplicar». Depois, crie uma sessão e escolha um modelo. Configuração e primeira tarefa.
