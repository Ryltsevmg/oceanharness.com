Computer Use

Seus aplicativos.
A ajuda do Ocean.

Permita que o Ocean leia a interface e execute tarefas nos aplicativos de que você precisa. Você decide o acesso a cada aplicativo.

01 Ativar plugin02 Configurar o sistema03 Testar no chat

Passo 01

Ative o plugin

Comece na seção «Plugins» da barra lateral do Ocean.

  1. Abra «Uso do computador»

    Ative a opção no cartão do plugin. Se o Ocean pedir para reiniciar, reinicie.

  2. Deixe o cartão aberto

    Aqui aparecem o estado do sistema e as permissões de acesso aos aplicativos.

Se o cartão não aparecer na lista, o plugin ainda não está instalado. Fale com o suporte e ajudaremos a instalar no seu sistema.

Passo 02

Prepare o sistema

Escolha seu sistema operacional. Os recursos do plugin variam entre plataformas.

macOS
  1. Nas linhas «Acessibilidade» e «Gravação de tela», clique em «Solicitar permissão».
  2. Nas configurações do sistema, autorize o acesso para o aplicativo indicado no painel do Ocean.
  3. Volte ao Ocean. As duas permissões devem mostrar o status «Permitido».

Após a configuração, ficam disponíveis leitura da interface, capturas de janelas, cliques, digitação e rolagem.

Windows
  1. Inicie o Ocean em uma sessão normal do Windows com a área de trabalho desbloqueada.
  2. No cartão, confira «Área de trabalho interativa» e «Captura de janelas».
  3. Para usar o mouse e o teclado, mantenha o aplicativo desejado em primeiro plano.

Estão disponíveis leitura da interface, capturas de janelas e controle. Aplicativos executados como administrador podem negar o acesso.

Se o componente nativo não estiver disponível, fale com o suporte para configurá-lo no seu sistema.

Linux
  1. Inicie o Ocean na sua sessão gráfica local e desbloqueie a área de trabalho.
  2. Confira a disponibilidade do AT-SPI no cartão. São necessários Python 3 do sistema, PyGObject e AT-SPI; o plugin não os instala automaticamente.
  3. Abra um aplicativo compatível com AT-SPI.

Estão disponíveis a leitura dos elementos da interface e as ações oferecidas pelo próprio aplicativo. Capturas de tela, entrada normal de mouse e teclado e abertura de aplicativos não são compatíveis.

Passo 03

Teste o acesso no chat

Para começar, basta ler uma janela. O modelo deve estar conectado no Ocean.

  1. Abra o aplicativo desejado

    Escolha uma janela sem dados pessoais, como um editor de texto com uma anotação de teste.

  2. Peça ao Ocean para observar a janela

    Leia a janela aberta do meu editor de texto e descreva brevemente o que aparece. Não altere nada.

    Informe o nome do editor se houver vários aplicativos abertos.

  3. Confirme o acesso

    O Ocean solicitará permissão para o aplicativo escolhido. Após a confirmação, lerá os elementos disponíveis e responderá no chat.

Você controla o acesso

Parar ou revogar

Clique em «Parar» no chat para interromper a tarefa atual. No cartão do plugin, clique em «Revogar» ao lado do aplicativo para remover a permissão.

A lista de aplicativos é preenchida após as solicitações de acesso. É normal estar vazia antes da primeira tarefa.
