Transparência sobre os dados

Seus dados no Ocean

Os chats são salvos no seu computador. Para responder, o Ocean envia o contexto ao modelo escolhido, e as ferramentas conectadas acessam os serviços necessários para a tarefa.

No dispositivo

Histórico de chats, configurações e conexões salvas.

No provedor do modelo

Mensagens e materiais incluídos na solicitação.

Sob seu controle

A escolha do modelo, dos plugins, dos sites e dos aplicativos.

O que é salvo localmente

No modo de desktop padrão, o Ocean salva o histórico de mensagens e ações das ferramentas, anexos, configurações e dados de conexão na pasta de dados do aplicativo. Por padrão, ela fica em ~/.ocean; você pode alterar o local em uma configuração própria.

As chaves API e os dados de autorização são salvos separadamente do texto das configurações. A proteção dos arquivos locais depende do acesso ao seu computador: esse armazenamento não é isolado de todas as ferramentas do agente.

O que o modelo recebe

A solicitação é enviada ao provedor que você conectou. Ela pode incluir mensagens do chat, arquivos lidos para a tarefa, texto de páginas, capturas de janelas e resultados de ferramentas. Salvar o histórico localmente não significa que o processamento do modelo também seja local.

Os prazos de retenção e o uso dos dados pelo provedor são definidos pelos termos dele e pelas configurações da sua conta. Serviços de busca, ferramentas externas e plugins de terceiros também têm suas próprias regras de tratamento de dados.

Navegador e aplicativos

Escolha os sites e aplicativos autorizados nas configurações do plugin correspondente. As capturas e o conteúdo lido podem fazer parte do chat e da solicitação ao modelo. Você pode revogar o acesso ou desativar o plugin.

As permissões, o pareamento e o armazenamento de dados da extensão do Chrome estão descritos separadamente: privacidade do Browser Control.

Envio de registros e diagnóstico

Ao usar o adaptador DeepSeek, existe a configuração separada «Enviar o registro com as solicitações à API DeepSeek» em «Configurações → Geral». Ela vem ativada na configuração base: o registro do chat, incluindo mensagens e resultados de ferramentas, é adicionado à solicitação API. Ao reativá-la, registros acumulados anteriormente também podem ser enviados.

O envio separado de registros para um serviço de telemetria está desativado na configuração base do Ocean. A análise de uso do produto exige um destinatário configurado explicitamente e ativação separada.

O adaptador DeepSeek também envia um identificador aleatório da instalação, mantido entre inicializações. Isso não depende da configuração de telemetria.

Se você usa uma configuração própria

A configuração pode incluir outros destinatários de dados. Quando ativado, o mecanismo integrado de envio de feedback transmite o registro até o momento do feedback, incluindo o contexto. Confira as configurações da sua compilação e dos provedores conectados.

Como gerenciar os dados salvos

Arquivar um chat o oculta da lista principal, mas não exclui seu registro. Remover um espaço de trabalho também não exclui a pasta nem o histórico de chats.

Para excluir todos os dados locais do Ocean, primeiro feche o aplicativo e salve os resultados necessários; depois, exclua a pasta de dados do aplicativo. Isso removerá os chats locais, as configurações e as conexões salvas de todos os perfis nessa pasta. Se os dados estiverem em um local personalizado, confirme o caminho com o suporteantes de excluir os arquivos.

Isso não exclui os arquivos dos seus projetos, backups externos, dados da extensão do Chrome ou materiais já enviados aos provedores. Gerencie esses dados no aplicativo ou serviço correspondente.

O que este site faz

O site não tem formulários de cadastro, rastreadores de publicidade ou contadores de terceiros incorporados. Fontes e imagens são carregadas do domínio do Ocean. A página de downloads consulta o GitHub para obter a lista de arquivos publicados.

O site é hospedado no GitHub Pages. Ao acessar o site, o GitHub ou links externos, os serviços correspondentes recebem os dados normais de uma solicitação de rede. As regras do GitHub estão descritas em sua declaração de privacidade.

Dúvidas sobre os dados

Fale com o suporte do Ocean ou escreva para support@oceanharness.com. Não anexe chaves API, senhas ou o registro completo do chat sem necessidade.
