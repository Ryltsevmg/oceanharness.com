Comece o mergulho

Do primeiro uso
à primeira tarefa.

Instale o Ocean, conecte um modelo e comece uma conversa. Você pode adicionar o navegador e os aplicativos depois.

01 Instalar Ocean 02 Conectar modelo 03 Propor uma tarefa

Passo 01

Instale o Ocean

Na página de downloads, escolha seu sistema e sua arquitetura.

Escolher download ↓
macOS
  1. Abra o DMG ou extraia o ZIP baixado.
  2. Mova o aplicativo Ocean para a pasta «Aplicativos».
  3. Inicie o Ocean a partir dessa pasta.

Apple silicon é indicado para chips Apple M. Confira o tipo de processador no menu Apple → «Sobre Este Mac».

Windows
  1. Baixe o instalador quando estiver disponível para seu sistema.
  2. Abra o arquivo e siga as etapas de instalação.
  3. Inicie o Ocean pelo menu «Iniciar».
Linux
  1. Extraia o arquivo TAR.GZ em uma pasta separada.
  2. Mantenha juntos todos os arquivos do pacote.
  3. Abra o terminal na pasta extraída e execute ./ocean.

O comando uname -m ajudará a escolher a arquitetura: x86_64 — x64, aarch64 — ARM64.

Passo 02

Conecte seu modelo

Para a primeira conversa, basta um provedor e sua chave API.

  1. Abra «Configurações» → «Modelos»

    Clique em «Adicionar provedor de modelos» e escolha um provedor no catálogo. Se ele já estiver na lista, abra «Editar».

  2. Adicione a chave API

    Obtenha a chave na sua conta do provedor, cole no campo «Chave API» e clique em «Aplicar».

  3. Confira se a chave foi salva

    O provedor mostrará «Chave API configurada». Vamos testar o modelo com a primeira mensagem.

Seu provedor define o acesso aos modelos e o custo das solicitações. Se você conectar uma conta por um plugin, o login é feito no cartão desse plugin.

Passo 03

Receba a primeira resposta

Comece com uma tarefa pequena. Este exemplo não precisa de acesso ao navegador ou aos aplicativos.

  1. Crie um chat

    Clique em «Nova sessão» no painel esquerdo. Na parte inferior do campo de mensagem, escolha o modelo conectado.

  2. Descreva a tarefa

    Experimente o exemplo da página inicial. Ele já inclui todo o contexto necessário:

    Crie um plano de reunião de equipe de 30 minutos. Precisamos combinar a data de lançamento, distribuir as tarefas restantes e escolher quem vai revisar o resultado. Destaque as decisões que precisamos tomar.

  3. Continue a conversa

    Envie a mensagem pelo botão de seta. Ao receber a resposta, ajuste a tarefa; por exemplo, peça para reduzir a reunião a 20 minutos.

Se a resposta não chegar

Confira o modelo escolhido, a chave API e o saldo disponível na sua conta do provedor. Se o Ocean mostrar um erro, fale com o suporte e inclua o texto do erro, sem chaves ou senhas.
