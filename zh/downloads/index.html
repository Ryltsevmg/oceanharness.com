首次启动前

几个简单步骤

安装应用，连接模型，开始对话。

首次启动指南 →
该选择哪种架构？

在 Mac 上打开 Apple 菜单 →“关于本机”：Apple M 芯片对应 Apple silicon，Intel 处理器对应 Intel。Windows 的架构信息位于“设置 → 系统 → 系统信息”。在 Linux 上，运行 uname -m 后，如果显示 x86_64 则选择 x64；如果显示 aarch64 则选择 ARM64。

如何安装 Ocean？

在 macOS 上打开 DMG 或解压 ZIP，然后将应用移到“应用程序”文件夹。在 Windows 上运行下载的安装程序。在 Linux 上解压 TAR.GZ，在终端中打开解压后的文件夹并运行 ./ocean。如果下载的是 AppImage，请在文件属性中允许执行。 详细安装说明.

安装后需要做什么？

打开“设置 → 模型”，点击“添加模型服务商”。填写连接信息后点击“应用”。然后新建会话并选择模型。 设置与第一个任务.
