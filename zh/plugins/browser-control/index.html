Browser Control

你的 Chrome。
Ocean 的能力。

在聊天中阅读页面、填写表单、管理标签页。网站登录状态保留在你常用的 Chrome 个人资料中。

开始使用

只需两步，
完成连接

从 Ocean 的“插件”→“浏览器控制”开始。

  1. 01

    安装扩展程序

    在 Ocean 中点击“安装扩展程序”，然后按照 Chrome 中的提示操作。

  2. 02

    连接到 Ocean

    返回应用并点击“连接”，然后选择允许访问的网站。

范围由你决定

标签页尽在掌控

Ocean 为每个聊天打开独立的标签页。要交出已打开的个人标签页，请使用 Chrome 中的扩展程序按钮。

仅完成连接不会让 Ocean 获得所有网站的访问权限。你可以在应用中修改权限。
