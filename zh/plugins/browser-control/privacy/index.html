Browser Control 隐私说明

自2026年11月16日起生效。本政策适用于 Ocean Browser Control Chrome 扩展程序。关于应用本身的聊天存储和数据处理，请参阅 “你在 Ocean 中的数据”.

扩展程序的功能

扩展程序将 Chrome 连接到已配对的中继服务，让 Ocean 可以控制任务标签页，以及你通过浏览器工具栏按钮交出的标签页。Ocean 单独提供允许访问的网站设置。Chrome 授予的权限比这一设置更广：限制在应用层执行，而非通过独立的 Chrome 沙箱实现。

处理哪些数据

根据请求，扩展程序可以读取页面文本与结构、网址、标签页标题、截图和字段值，也可以点击元素、输入文字和管理标签页。页面可能包含个人信息、身份验证信息、财务、医疗等敏感信息。中继服务还支持按请求录制已交出的标签页。网站登录状态保留在你的 Chrome 个人资料中，并通过普通浏览器会话使用。

数据发送到哪里

默认情况下，扩展程序与电脑上的中继服务交换命令和结果。在高级设置中，可以指定你选择的另一台电脑上的服务。请仅使用可信任的服务和网络。Ocean 可能将页面内容和截图发送给为任务选择的模型服务商；此时适用该服务商的条款和隐私政策。扩展程序本身不会选择模型服务商。

扩展程序不包含广告或分析服务，也不会将浏览器数据发送到 Ocean 的数据收集服务器。浏览器数据仅用于执行所请求的操作，不会出售，也不会用于广告、用户画像或无关目的。数据的使用和传输符合 Chrome Web Store 的用户数据政策及 Limited Use 要求。

存储与删除

扩展程序将配对数据和设置保存在 Chrome 扩展程序存储空间中。中继服务的访问凭据和 Ocean 任务记录单独保存。卸载扩展程序会删除其本地存储，但不会删除 Ocean 聊天日志、中继服务文件或已经发送给模型服务商的副本；这些数据需要在对应的应用或服务中管理。

Chrome 权限

  • debugger: 通过 Chrome DevTools Protocol 查看交出的页面、截取屏幕以及执行浏览器操作。
  • tabs 和 tabGroups： 管理任务标签页，并按智能体会话分组。
  • storage: 在本地保存配对数据和设置。
  • alarms: 在扩展程序的后台进程暂停后，重新连接到中继服务。
  • offscreen 和 tabCapture： 处理对已交出标签页的录制请求。
  • webNavigation: 将弹出窗口和导航与任务标签页关联。
  • scripting: 运行扩展程序内置的页面操作辅助脚本。
  • notifications: 任务需要你参与时发送通知。
  • 访问所有网站： 操作用户选择的网站，并与已配置的服务通信。扩展程序不会请求访问整个浏览历史数据库。

你的控制权

在 Ocean 中选择允许访问的网站，明确交出已有标签页；要停止使用，请关闭插件或扩展程序。在包含敏感数据的页面上执行操作前，请检查任务。如果不打算向所选模型服务商传递秘密信息，请勿将其输入任务中。

联系方式

如有隐私问题或数据相关请求，请发送邮件至 support@oceanharness.com 或联系 Ocean 支持。本政策如有更新，将在此页面发布，并注明新的生效日期。
