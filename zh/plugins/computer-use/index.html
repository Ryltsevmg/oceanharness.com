Computer Use

你的应用。
Ocean 的帮助。

允许 Ocean 读取所需应用的界面并执行任务。每个应用的访问权限都由你决定。

01 启用插件02 设置系统03 在聊天中测试

步骤 01

启用插件

从 Ocean 侧边栏的“插件”开始。

  1. 打开“计算机使用”

    打开插件卡片中的开关。如果 Ocean 提示重启，请按提示重启。

  2. 保持卡片打开

    这里显示系统准备状态以及应用访问权限。

如果列表中没有这张卡片，说明插件尚未安装。 联系支持 ，我们会帮助你为当前系统完成安装。

步骤 02

准备系统

选择操作系统。插件功能因平台而异。

macOS
  1. 在“辅助功能”和“屏幕录制”两行中点击“请求权限”。
  2. 在系统设置中，为 Ocean 面板所列的应用允许访问。
  3. 返回 Ocean。两项权限都应显示“已允许”。

设置完成后，即可读取界面、截取窗口、点击、输入文字和滚动。

Windows
  1. 在普通 Windows 会话中启动 Ocean，并保持桌面解锁。
  2. 在卡片中检查“交互式桌面”和“窗口捕获”。
  3. 进行鼠标和键盘操作时，请让目标应用保持在前台。

支持界面读取、窗口截图和操作。以管理员身份运行的应用可能拒绝访问。

如果原生组件不可用，请 联系支持 ，为你的系统完成配置。

Linux
  1. 在本地图形会话中启动 Ocean，并解锁桌面。
  2. 在卡片中检查 AT-SPI 是否可用。需要系统 Python 3、PyGObject 和 AT-SPI；插件不会自动安装这些组件。
  3. 打开支持 AT-SPI 的应用。

支持读取界面元素，以及执行应用自身提供的操作。不支持截图、常规鼠标和键盘输入，也不支持启动应用。

步骤 03

在聊天中验证访问

先尝试读取窗口即可。请先 在 Ocean 中连接模型.

  1. 打开目标应用

    选择不含个人信息的窗口，例如打开了一条测试笔记的文本编辑器。

  2. 请 Ocean 查看窗口

    读取我当前打开的文本编辑器窗口，简要描述其中可见的内容。不要做任何修改。

    如果打开了多个应用，请说明编辑器的名称。

  3. 确认访问权限

    Ocean 会请求访问所选应用。确认后，它会读取可访问的元素，并在聊天中回复。

访问权由你掌控

停止或撤销权限

点击聊天中的“停止”可中断当前任务。在插件卡片中，点击应用旁的“撤销”可取消其访问权限。

应用列表会在请求访问权限后填充。第一个任务前列表为空是正常状态。
