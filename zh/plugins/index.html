Browser Control

浏览器控制

使用保留登录状态的 Chrome。在聊天中阅读页面、填写表单、管理标签页。

由你选择允许访问的网站，也可以将已打开的标签页交给 Ocean。

Computer Use

应用控制

在已授权的应用中读取界面、截取窗口、点击、输入文字和滚动。

在 Ocean 的“插件”中设置访问权限。可用操作因操作系统而异。

Super Agent

任务看板

持久化的开发看板：智能体在独立的 git 工作树中领取任务，运行仓库检查并返回结果。

任务比会话活得更久：看板保留，执行器把任务推进到经过验证的结果。

Agent Developer Patterns

智能体开发模式

调度型技能：先判断你处于哪个阶段，再给出一份现成的流程——计划、访谈、TDD、假设驱动调试、评审或交接。

仅靠该捆绑包即可运行，额外的技能集不是必需的。

Remotion studio

影片工作室

从模板生成 Remotion 项目，在 Studio 中预览，并直接在对话里渲染 MP4。

渲染在后台任务中进行，长时间的编码不会阻塞对话。

Theme picker

界面主题

二十七套配色：Abyss、One Dark/Light、Dracula/Alucard、GitHub、Solarized、Nord、Tokyo Night、Catppuccin、Gruvbox、Everforest、Rosé Pine、Kanagawa、Ayu、Night Owl、Material、Flexoki、Modus、Darcula、Mariana、Oxocarbon、PaperColor、Seoul256、Monokai、SynthWave '84、Cobalt2、Horizon 和 Jellybeans。

一个选择器捆绑包即可在明暗两种方案下重绘界面，并且不取代「外观」设置。
