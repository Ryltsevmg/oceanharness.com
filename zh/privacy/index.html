透明说明数据处理

你在 Ocean 中的数据

聊天保存在你的电脑上。为生成回复，Ocean 会向所选模型传递上下文，已连接的工具则会访问任务所需的服务。

在设备上

聊天记录、设置和已保存的连接。

在模型服务商处

请求中包含的消息和资料。

由你掌控

选择模型、插件、网站和应用。

哪些数据保存在本地

在普通桌面模式下，Ocean 将消息和工具操作历史、附件、设置及连接数据保存在应用数据文件夹中。默认位置为 ~/.ocean；你可以通过自定义配置更改位置。

API 密钥和授权数据与设置文本分开保存。本地文件的安全性取决于谁能访问你的电脑：这些数据并非存放在与所有智能体工具隔离的存储区中。

模型会收到什么

请求会发送给你连接的服务商。请求可能包含聊天消息、为任务读取的文件、页面文本、窗口截图和工具结果。历史记录保存在本地，并不意味着模型处理也在本地进行。

服务商侧的数据保留期限和使用方式由其条款及你的账号设置决定。搜索服务、外部工具和第三方插件也各有自己的数据处理规则。

浏览器和应用

在对应插件的设置中选择允许访问的网站和应用。截图及读取的内容可能成为聊天和模型请求的一部分。你可以撤销访问权限或关闭插件。

Chrome 扩展程序的权限、配对和数据存储方式另有说明： Browser Control 隐私说明.

日志发送与诊断

DeepSeek 适配器提供单独的 “随 DeepSeek API 请求发送日志” 设置，位于“设置 → 常规”。基础配置中默认启用：聊天日志（包括消息和工具结果）会附加到 API 请求中。重新启用此设置后，也可能发送此前积累的记录。

Ocean 基础配置中默认关闭向遥测服务单独发送日志的功能。产品分析需要明确配置接收方，并单独启用。

DeepSeek 适配器还会发送一个随机生成的安装标识符，该标识符在多次启动之间保持不变。这不受遥测设置影响。

如果使用自定义配置

配置中可能包含其他数据接收方。内置反馈机制启用后，会发送反馈提交前的日志，包括上下文。请检查所用构建和已连接服务商的设置。

如何管理已保存的数据

归档会将聊天从主列表中隐藏，但不会删除其日志。删除工作空间也不会删除其文件夹或聊天历史。

要删除 Ocean 的全部本地数据，请先关闭应用并保存需要的结果，再删除应用数据文件夹。该文件夹内所有配置文件的本地聊天、设置和已保存连接都会一并删除。如果数据保存在非默认位置，请在删除文件前 向支持团队确认路径。

这不会删除项目文件、外部备份、Chrome 扩展程序数据或已发送给服务商的资料。这些数据需要在对应的应用或服务中管理。

本网站如何运作

本网站没有注册表单、广告跟踪器或内嵌的第三方统计工具。字体和图片从 Ocean 域名加载。下载页面会向 GitHub 请求已发布文件列表。

本网站托管于 GitHub Pages。访问网站、GitHub 或外部链接时，相应服务会收到常规网络请求数据。GitHub 的相关规则请参阅 其隐私声明.

数据相关问题

请联系 Ocean 支持 或发送邮件至 support@oceanharness.com。请勿在不必要的情况下附上 API 密钥、密码或完整聊天日志。
