开始下潜

从首次启动
到第一个任务。

安装 Ocean，连接模型，开始对话。浏览器和应用可以稍后再连接。

01 安装 Ocean 02 连接模型 03 提出任务

步骤 01

安装 Ocean

在下载页面选择操作系统和架构。

选择下载 ↓
macOS
  1. 打开 DMG，或解压下载的 ZIP。
  2. 将 Ocean 应用移到“应用程序”文件夹。
  3. 从该文件夹启动 Ocean。

Apple silicon 适用于 Apple M 芯片。处理器类型可以在 Apple 菜单 →“关于本机”中查看。

Windows
  1. 当你的系统有可用安装程序时，下载安装程序。
  2. 打开文件，按步骤完成安装。
  3. 从“开始”菜单启动 Ocean。
Linux
  1. 将 TAR.GZ 压缩包解压到单独的文件夹。
  2. 请将压缩包中的所有文件保存在一起。
  3. 在解压后的文件夹中打开终端并运行 ./ocean.

运行命令 uname -m 可帮助选择架构： x86_64 — x64, aarch64 — ARM64.

步骤 02

连接自己的模型

第一次对话只需要一个服务商及其 API 密钥。

  1. 打开“设置”→“模型”

    点击“添加模型服务商”，从目录中选择服务商。如果已在列表中，请打开“编辑”。

  2. 添加 API 密钥

    从服务商的账号控制台获取密钥，粘贴到“API 密钥”字段，然后点击“应用”。

  3. 确认密钥已保存

    服务商旁会显示“API 密钥已配置”。发送第一条消息即可验证模型是否正常工作。

可用模型和请求费用由你的服务商决定。如果通过插件连接账号，请在该插件的卡片中登录。

步骤 03

获取第一个回复

从小任务开始。这个示例无需访问浏览器或应用。

  1. 创建聊天

    点击左侧面板中的“新建会话”，在消息框底部选择已连接的模型。

  2. 描述任务

    试试首页的示例，其中已包含所有必要背景：

    制定一个 30 分钟的团队会议计划。我们需要商定发布日期、分配剩余任务，并决定由谁检查结果。请列出需要做出的决定。

  3. 继续对话

    点击箭头按钮发送消息。收到回复后，可进一步细化任务，例如请它将会议缩短到 20 分钟。
